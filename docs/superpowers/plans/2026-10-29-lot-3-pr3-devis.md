# Lot 3 — PR 3 « Devis » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sur la synthèse des étapes 3.1 et 3.2, permettre à un coordinateur de demander un devis à un prestataire vérifié. Il relit un message WhatsApp préparé en code, la demande est tracée dans `quote_request`, puis `wa.me` s'ouvre. La synthèse liste ensuite les « Devis demandés » de l'étape.

**Architecture:**
- Le module `providers` reçoit :
  - un constructeur de message pur, `quote-message.ts` ;
  - les fonctions de dépôt et de service des demandes ;
  - une action serveur ;
  - deux composants : le formulaire client de la demande et l'historique.
- Le numéro WhatsApp ne quitte le serveur qu'au retour de l'action, une fois la demande tracée.
- Une petite migration fige le nom du prestataire dans `quote_request.provider_name`. Sans elle, un prestataire désactivé disparaîtrait de l'historique, car la RLS le cache aux familles.

**Tech Stack:** Next.js 15 App Router, React 19, next-intl 3, Zod, Supabase (RLS, trigger `security definer`), Vitest + Testing Library, PGlite pour les tests SQL, pnpm.

```sql
-- Lot 3, PR 3 : nom du prestataire figé dans la demande de devis.
-- WHY: la RLS cache un prestataire désactivé aux familles ; l'historique « Devis demandés » doit
-- pourtant le nommer. Le trigger, security definer, lit le nom au moment de la demande.

alter table public.quote_request add column provider_name text;

update public.quote_request q
set provider_name = p.name
from public.provider p
where p.id = q.provider_id;

alter table public.quote_request alter column provider_name set not null;

create or replace function public.quote_request_before_insert()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  reachable_name text;
begin
  if not public.is_dossier_member(new.dossier_id, 'coordinator') then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  select p.name into reachable_name
  from public.provider p
  where p.id = new.provider_id and p.active and not p.is_example
    and p.whatsapp is not null and p.verified_at is not null;
  if reachable_name is null then
    raise exception 'provider not reachable' using errcode = 'TL010';
  end if;
  new.provider_name := reachable_name;
  new.created_by := auth.uid();
  new.created_at := now();
  return new;
end;
$$;

revoke execute on function public.quote_request_before_insert() from public, anon, authenticated;
```

WHY du `update` : la production n'a aucune demande (pas d'interface avant cette PR), mais le remplissage rend la migration sûre si une ligne existe. `provider.name` est `not null`, donc chaque ligne reçoit un nom.

```ts
import type { Quantity, QuantityKey } from '@/journey/quantities';
import type { ProviderCategory } from './categories';

/** Longueur maximale d'un message, comme la contrainte de `quote_request.message`. */
export const QUOTE_MESSAGE_MAX = 2000;

// WHY: chaque prestataire ne reçoit que les besoins qui le concernent ; une catégorie absente
// (pompes funèbres, imprimeur) n'en reçoit aucun.
const CATEGORY_QUANTITIES: Partial<Record<ProviderCategory, readonly QuantityKey[]>> = {
  tentsChairs: ['tents', 'chairs', 'benchPlaces'],
  sound: ['soundSystems'],
  lighting: ['lightSets'],
  catering: ['platesPerNight', 'funeralPlates'],
  drinks: ['waterPacks', 'drinkBottles', 'iceKg'],
};

type Translate = (key: string, values?: Record<string, string | number>) => string;

export interface QuoteMessageInput {
  providerName: string;
  category: ProviderCategory;
  /** Ville du lieu de la veillée, sinon du décès. */
  place: string;
  /** Date déjà formatée, ou null (« à préciser »). */
  date: string | null;
  quantities: readonly Quantity[];
}

/** Quantités d'une estimation utiles à une catégorie, dans l'ordre de l'estimation. */
export function quantitiesFor(
  category: ProviderCategory,
  quantities: readonly Quantity[],
): Quantity[] {
  const keys = CATEGORY_QUANTITIES[category] ?? [];
  return quantities.filter((quantity) => keys.includes(quantity.key));
}

/**
 * Message de demande de devis, construit sans IA. Ne contient jamais le nom de la personne
 * décédée : seuls le besoin, la date, le lieu et les quantités sortent du dossier.
 * `t` est un traducteur sans espace de noms.
 *
 * @example
 * quoteMessage({ providerName: 'Tentes Owendo', category: 'tentsChairs', place: 'Libreville',
 *   date: null, quantities }, t);
 */
export function quoteMessage(input: QuoteMessageInput, t: Translate): string {
  const lines = [
    t('providers.quote.message.greeting', { name: input.providerName }),
    t('providers.quote.message.need', { category: t(`providers.category.${input.category}`) }),
    t('providers.quote.message.date', {
      date: input.date ?? t('providers.quote.message.dateUnknown'),
    }),
    t('providers.quote.message.place', { place: input.place }),
  ];
  const needs = quantitiesFor(input.category, input.quantities);
  if (needs.length > 0) {
    lines.push(t('providers.quote.message.quantities'));
    for (const need of needs) {
      lines.push(`- ${t(`journey.synthesis.quantity.${need.key}`, { count: need.count })}`);
    }
  }
  lines.push(t('providers.quote.message.closing'));
  return lines.join('\n').slice(0, QUOTE_MESSAGE_MAX);
}

/**
 * Lien d'ouverture de WhatsApp vers le prestataire, message prérempli.
 *
 * @example
 * quoteHref('+24177123456', 'Bonjour'); // 'https://wa.me/24177123456?text=Bonjour'
 */
export function quoteHref(whatsapp: string, message: string): string {
  return `https://wa.me/${whatsapp.replace(/^\+/, '')}?text=${encodeURIComponent(message)}`;
}
```

```ts
import 'server-only';
import { getSupabaseServer } from '@/lib/supabase/server';
import type { RepoResult } from '@/modules/dossier/repo';

/** Étapes dont la synthèse propose des devis (contrainte de `quote_request.step_id`). */
export const QUOTE_STEPS = ['vigil-setup', 'vigil-catering', 'ceremony-program'] as const;
export type QuoteStep = (typeof QUOTE_STEPS)[number];

/** WHY: au-delà, l'historique d'une étape ne sert plus ; il reste lisible en base. */
const HISTORY_LIMIT = 50;

export interface QuoteRequestRow {
  id: string;
  providerName: string;
  createdBy: string | null;
  createdAt: string;
}

function fail(error: { code?: string; message?: string }) {
  return {
    data: null,
    error: { code: error.code || 'unknown', message: error.message || 'quotes error' },
  };
}

/**
 * Trace une demande de devis. Auteur, date et nom du prestataire sont imposés par le trigger ;
 * TL010 si le prestataire n'est plus contactable, 42501 sous le rôle coordinateur.
 */
export async function insertQuoteRequest(input: {
  dossierId: string;
  providerId: string;
  stepId: QuoteStep;
  message: string;
}): Promise<RepoResult<{ id: string }>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('quote_request')
    .insert({
      dossier_id: input.dossierId,
      provider_id: input.providerId,
      step_id: input.stepId,
      message: input.message,
    })
    .select('id')
    .single();
  if (error) return fail(error);
  return { data: { id: (data as { id: string }).id }, error: null };
}

/** Demandes de devis d'une étape (RLS : membres du dossier), les plus récentes d'abord. */
export async function listQuoteRequests(
  dossierId: string,
  stepId: QuoteStep,
): Promise<RepoResult<QuoteRequestRow[]>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('quote_request')
    .select('id, provider_name, created_by, created_at')
    .eq('dossier_id', dossierId)
    .eq('step_id', stepId)
    .order('created_at', { ascending: false })
    .limit(HISTORY_LIMIT)
    .returns<
      { id: string; provider_name: string; created_by: string | null; created_at: string }[]
    >();
  if (error) {
    console.error('[providers] listQuoteRequests impossible', { code: error.code });
    return fail(error);
  }
  return {
    data: (data ?? []).map((r) => ({
      id: r.id,
      providerName: r.provider_name,
      createdBy: r.created_by,
      createdAt: r.created_at,
    })),
    error: null,
  };
}
```

```ts
import 'server-only';
import { z } from 'zod';
import { listMembers } from '@/modules/dossier/repo';
import { QUOTE_MESSAGE_MAX, quoteHref } from './quote-message';
import { insertQuoteRequest, listQuoteRequests, QUOTE_STEPS, type QuoteStep } from './quote-repo';
import { getProvider } from './repo';

export type QuoteError =
  | 'validation'
  | 'forbidden'
  | 'unreachable'
  | 'unauthenticated'
  | 'unknown';

export type QuoteResult<T> = { ok: true; data: T } | { ok: false; error: QuoteError };

/** Ligne de l'historique « Devis demandés ». */
export interface QuoteHistoryItem {
  id: string;
  providerName: string;
  /** Nom affiché de l'auteur, null s'il a quitté le dossier ou n'a pas de nom. */
  author: string | null;
  createdAt: string;
}

const CODES: Record<string, QuoteError> = {
  '42501': 'forbidden',
  '28000': 'unauthenticated',
  '23514': 'validation',
  '22P02': 'validation',
  TL010: 'unreachable',
};

const RequestSchema = z.object({
  dossierId: z.string().uuid(),
  providerId: z.string().uuid(),
  stepId: z.enum(QUOTE_STEPS),
  message: z.string().trim().min(1).max(QUOTE_MESSAGE_MAX),
});

function fromRepo(error: { code: string }, scope: string): { ok: false; error: QuoteError } {
  const mapped = CODES[error.code];
  if (!mapped) console.error(`[providers] ${scope} failed`, { code: error.code });
  return { ok: false, error: mapped ?? 'unknown' };
}

/**
 * Trace une demande de devis puis renvoie le lien `wa.me` vers le prestataire.
 * WHY: le numéro ne quitte le serveur qu'après la trace ; une demande refusée (rôle, prestataire
 * plus contactable) n'ouvre rien.
 *
 * @example
 * const res = await requestQuote({ dossierId, providerId, stepId: 'vigil-setup', message });
 * if (res.ok) window.open(res.data.href);
 */
export async function requestQuote(raw: unknown): Promise<QuoteResult<{ href: string }>> {
  const parsed = RequestSchema.safeParse(raw);
  if (!parsed.success) return { ok: false, error: 'validation' };
  const inserted = await insertQuoteRequest(parsed.data);
  if (inserted.error) return fromRepo(inserted.error, 'requestQuote');
  const provider = await getProvider(parsed.data.providerId);
  // WHY: le trigger vient de vérifier le prestataire ; s'il n'est plus lisible (désactivé dans
  // l'intervalle), la demande reste tracée mais aucun numéro n'est donné.
  if (provider.error || !provider.data.whatsapp) return { ok: false, error: 'unreachable' };
  return { ok: true, data: { href: quoteHref(provider.data.whatsapp, parsed.data.message) } };
}

/**
 * Historique « Devis demandés » d'une étape, avec le nom affiché de l'auteur.
 *
 * @example
 * const res = await quotesForStep(dossierId, 'vigil-setup');
 */
export async function quotesForStep(
  dossierId: string,
  stepId: QuoteStep,
): Promise<QuoteResult<QuoteHistoryItem[]>> {
  const res = await listQuoteRequests(dossierId, stepId);
  if (res.error) return fromRepo(res.error, 'quotesForStep');
  if (res.data.length === 0) return { ok: true, data: [] };
  const names = new Map(
    (await listMembers(dossierId)).map((member) => [member.userId, member.displayName]),
  );
  return {
    ok: true,
    data: res.data.map((row) => ({
      id: row.id,
      providerName: row.providerName,
      author: (row.createdBy && names.get(row.createdBy)) || null,
      createdAt: row.createdAt,
    })),
  };
}
```

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { getLocale } from 'next-intl/server';
import { localizedPath } from '@/lib/auth/redirect-target';
import { getCurrentUser } from '@/lib/supabase/server';
import { type QuoteError, requestQuote } from './quote-service';

export interface QuoteFormState {
  ok?: boolean;
  /** Lien `wa.me` à ouvrir, présent quand la demande est tracée. */
  href?: string;
  error?: QuoteError;
}

const field = (formData: FormData, name: string) => String(formData.get(name) ?? '');

/**
 * Trace une demande de devis et renvoie le lien WhatsApp.
 * WHY: la synthèse est revalidée pour que l'historique « Devis demandés » montre la demande.
 */
export async function requestQuoteAction(
  _prev: QuoteFormState | null,
  formData: FormData,
): Promise<QuoteFormState> {
  if (!(await getCurrentUser())) return { error: 'unauthenticated' };
  const input = {
    dossierId: field(formData, 'dossierId'),
    providerId: field(formData, 'providerId'),
    stepId: field(formData, 'stepId'),
    message: field(formData, 'message'),
  };
  const res = await requestQuote(input);
  if (!res.ok) return { error: res.error };
  revalidatePath(
    localizedPath(`/dossier/${input.dossierId}/etape/${input.stepId}/synthese`, await getLocale()),
  );
  return { ok: true, href: res.data.href };
}
```

```tsx
'use client';

import { startTransition, useActionState, useEffect, useId, useState, type FormEvent } from 'react';
import { useTranslations } from 'next-intl';
import { buttonClasses } from '@/components/ui/Button';
import { QUOTE_MESSAGE_MAX } from '../quote-message';
import { type QuoteFormState, requestQuoteAction } from '../quote-actions';
import type { QuoteStep } from '../quote-repo';
import { quoteErrorText } from './quoteError';

interface Props {
  dossierId: string;
  providerId: string;
  providerName: string;
  stepId: QuoteStep;
  /** Message préparé côté serveur, modifiable par la famille. */
  message: string;
}

/**
 * « Demander un devis » : le message préparé s'affiche, la famille le relit, puis « Ouvrir
 * WhatsApp » trace la demande et ouvre `wa.me`. Le lien reste affiché si l'ouverture échoue.
 *
 * @example
 * <QuoteRequestForm dossierId={id} providerId={p.id} providerName={p.name}
 *   stepId="vigil-setup" message={message} />
 */
export function QuoteRequestForm({ dossierId, providerId, providerName, stepId, message }: Props) {
  const t = useTranslations('providers.quote');
  const tRoot = useTranslations();
  const fieldId = useId();
  const [open, setOpen] = useState(false);
  const [state, formAction, pending] = useActionState<QuoteFormState | null, FormData>(
    requestQuoteAction,
    null,
  );

  // WHY: l'ouverture suit l'aller-retour serveur ; un bloqueur de fenêtres peut la refuser,
  // d'où le lien affiché en dessous.
  useEffect(() => {
    if (state?.href) window.open(state.href, '_blank', 'noopener,noreferrer');
  }, [state]);

  const submit = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (pending) return;
    const data = new FormData(e.currentTarget);
    startTransition(() => formAction(data));
  };

  if (!open) {
    return (
      <button
        type="button"
        onClick={() => setOpen(true)}
        className={buttonClasses({ variant: 'secondary', size: 'sm' })}
      >
        {t('request')}
      </button>
    );
  }

  return (
    <form onSubmit={submit} className="space-y-2">
      <input type="hidden" name="dossierId" value={dossierId} />
      <input type="hidden" name="providerId" value={providerId} />
      <input type="hidden" name="stepId" value={stepId} />
      <label htmlFor={fieldId} className="text-foreground block text-sm font-semibold">
        {t('messageLabel', { name: providerName })}
      </label>
      <p id={`${fieldId}-hint`} className="text-muted-foreground text-xs">
        {t('messageHint')}
      </p>
      <textarea
        id={fieldId}
        name="message"
        defaultValue={message}
        required
        maxLength={QUOTE_MESSAGE_MAX}
        rows={8}
        aria-describedby={`${fieldId}-hint`}
```

```ts
import type { Quantity } from '@/journey/quantities';
import type { PanelGroup } from './panel';
import { quoteMessage } from './quote-message';

type Translate = (key: string, values?: Record<string, string | number>) => string;

const isPlace = (value: unknown): value is { city: string } =>
  typeof value === 'object' &&
  value !== null &&
  typeof (value as { city?: unknown }).city === 'string';

/** Ville du message : celle du lieu de la veillée (réponse `vigil.place`), sinon celle de l'encadré. */
export function quotePlace(placeAnswer: unknown, panelCity: string): string {
  const city = isPlace(placeAnswer) ? placeAnswer.city.trim() : '';
  return city || panelCity;
}

/**
 * Messages de devis par prestataire contactable de l'encadré (vérifié, non exemple, avec
 * numéro), indexés par identifiant.
 */
export function quoteMessages(
  groups: readonly PanelGroup[],
  context: { place: string; date: string | null; quantities: readonly Quantity[] },
  t: Translate,
): Record<string, string> {
  const messages: Record<string, string> = {};
  for (const group of groups) {
    for (const provider of group.providers) {
      if (provider.isExample || !provider.verifiedAt || !provider.whatsapp) continue;
      messages[provider.id] = quoteMessage(
        { providerName: provider.name, category: group.category, ...context },
        t,
      );
    }
  }
  return messages;
}
```
