# Lot 2 · PR 5 — Bilan et clôture : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un écran « Bilan » (troisième onglet des cotisations) montre le budget de référence, le reçu, le promis non versé, le dépensé, le reste et les dépenses par poste, propose un texte de synthèse partageable (totaux seulement) et l'export CSV du registre ; le trésorier clôture les cotisations, le propriétaire seul les rouvre, et un dossier clôturé refuse toute écriture financière.

**Architecture:** une migration ajoute `dossier_finance.closed_at` et `closed_by` (droits de colonne : seules les fonctions `close_ledger` et `reopen_ledger` les écrivent), un journal `ledger_closure_event` (qui, quand) et un contrôle commun `ledger_assert_open` (code `TL009`) appelé par les triggers du registre, des postes et des reçus et par `set_budget_scenario`. Côté web, un module `apps/web/src/modules/budget/closing/` (schéma, dépôt, service, actions, texte de synthèse, CSV, route d'export, composants) ; les services existants traduisent `TL009` en erreur typée `closed` ; les écrans Cotisations, Postes et le tableau de bord affichent l'état « clôturé ».

**Tech Stack:** Supabase (Postgres 17, RLS, droits de colonne, PGlite pour les tests SQL), Next.js 15 (Server Components, server actions, route handlers), React 19, next-intl 3, Zod 3, Vitest (+ jsdom pour les composants), Playwright (smoke).

Spec : `docs/superpowers/specs/2026-10-27-lot-2-financer-design.md` (« Décisions prises » : Bilan ; § 1 `dossier_finance`, `budget_line`, `ledger_entry` — refus quand le dossier est clôturé, suppression d'un dossier qui a un registre —, `receipt` ; § 2 « Écrans » : Bilan ; § 4 « Erreurs », « Tests », « Livraison » point 5, « Hors lot 2 » : pas de PDF, pas de lien public vers le bilan).

Branche : `feature/lot2-pr5-closing`, créée par-dessus `feature/lot2-pr4-receipts` (PR 4 pas encore fusionnée). Ne pas changer de branche.

## Décisions de ce plan (à valider dans la PR)

- **Où vérifier « clôturé » :** en base d'abord, par une fonction interne `ledger_assert_open(p_dossier_id)` (security definer, `search_path` vide, non exécutable par `anon` ni `authenticated`) qui lève `TL009`. Elle est appelée par le trigger d'insertion du registre (après le contrôle du rôle et après le rejeu d'une clé d'idempotence, pour qu'un double envoi d'une ligne déjà enregistrée renvoie toujours `23505`), par les triggers d'insertion, de modification et (nouveau) de suppression de `budget_line`, par les triggers d'insertion et de rattachement de `receipt`, et par `set_budget_scenario`. Le rôle est toujours vérifié avant (`42501`) : un non-membre ne sonde pas l'état du dossier. Dans le web, chaque service traduit `TL009` en erreur typée `closed` (registre, postes, reçus) ; le service des reçus vérifie en plus la clôture **avant** de préparer un envoi ou de lire une photo, pour ne pas consommer le quota d'IA.
- **Concurrence :** `ledger_assert_open` prend un verrou partagé (`for share`) sur la ligne du dossier ; `close_ledger` et `reopen_ledger` prennent un verrou exclusif (`for no key update`) sur la même ligne. Une écriture en cours finit donc avant la clôture, et une écriture qui suit la voit. Les écritures entre elles ne se bloquent pas. Si la ligne du dossier n'existe plus (suppression en cascade d'un dossier), le contrôle ne refuse rien : il n'y a plus rien à protéger. PGlite ne teste pas la concurrence ; le raisonnement est consigné dans la migration.
- **Clôture et réouverture :** `close_ledger(p_dossier_id) returns timestamptz` (trésorier et plus) et `reopen_ledger(p_dossier_id) returns void` (propriétaire seul), security definer, `search_path` vide, utilisateur connecté exigé (`28000`) puis rôle (`42501`) en premier. Idempotentes : clôturer un dossier clôturé renvoie la date de la première clôture et garde son auteur ; rouvrir un dossier ouvert ne fait rien. Aucun événement n'est journalisé quand rien ne change.
- **Colonnes protégées :** `revoke insert, update on dossier_finance from authenticated`, puis `grant insert (dossier_id, amounts_visibility)` et `grant update (dossier_id, amounts_visibility)`. Le propriétaire garde son réglage de visibilité (l'upsert de supabase-js réécrit aussi `dossier_id`, que le trigger fige) ; `scenario`, `closed_at` et `closed_by` ne s'écrivent plus que par les fonctions security definer. Conséquence : une mise à jour directe de `scenario` donne désormais `42501` au lieu d'une mise à jour sans effet (test de `budget-lines.test.ts` adapté).
- **Journal minimal :** table `ledger_closure_event` (`dossier_id`, `action` `close` / `reopen`, `actor_id`, `created_at`), en ajout seul, écrite seulement par les deux fonctions, lisible par trésorier et plus. `dossier_finance.closed_at` / `closed_by` donnent l'état courant.
- **Visibilité :** le réglage de visibilité des montants individuels reste modifiable une fois clôturé (il ne change aucun montant ; le propriétaire peut vouloir ouvrir le détail au moment du bilan). À confirmer dans la PR.
- **Archivage et export :** « archivé » = clôturé : le registre est figé en lecture seule et conservé. L'export est un fichier CSV (UTF-8 avec BOM, séparateur `;`, cellules entre guillemets, cellules commençant par `=`, `+`, `-`, `@`, tabulation ou retour chariot préfixées d'une apostrophe contre l'injection de formules), téléchargeable par le trésorier et plus, à tout moment, depuis l'écran Bilan. Il est généré côté serveur par la route `/api/dossiers/[dossierId]/ledger-export?lang=fr|en` avec le client utilisateur (RLS : le trésorier voit toutes les lignes), jamais service-role ; 401 sans session, 404 si le dossier est absent, interdit ou hors budget, 413 au-delà de 50 000 lignes (refus plutôt que fichier tronqué).
- **Suppression d'un dossier :** la règle la plus sûre est gardée. `ledger_entry.dossier_id` reste en `on delete restrict` : un dossier qui a un registre ne se supprime pas, même clôturé (`23001`). Aucune donnée financière n'est effacée ; l'export CSV sert d'archive à la famille. Un dossier sans registre se supprime toujours, clôturé ou non (ses postes, son journal et sa ligne `dossier_finance` partent avec lui). La spec est mise à jour en ce sens ; une politique de conservation (durée, effacement) est hors lot 2.
- **Écran Bilan :** à l'adresse `/dossier/[id]/cotisations/bilan`, troisième onglet après « Mouvements » et « Postes » (la spec disait `/dossier/[id]/bilan` ; l'onglet garde les trois vues ensemble, la spec est mise à jour). Contenu : état (clôturé le … / bilan provisoire), chiffres clés (`LedgerSummary`, déjà utilisé par Cotisations), dépenses par poste (postes qui ont des dépenses, « Sans poste », total), cotisations reçues nominatives **telles que la RLS les montre** (toutes pour trésorier et plus ou en mode `members`, sinon les siennes, avec un titre adapté), texte à partager, export (trésorier et plus), clôture (trésorier et plus) et réouverture (propriétaire).
- **Texte de synthèse :** construit côté serveur par une fonction pure (`summaryText`) à partir des totaux de `ledger_totals`, visibles de tout membre : budget de référence, reçu, promis non versé, dépensé, disponible, reste, et « clôturées le … » ou « bilan provisoire ». Aucun nom de contributeur, aucun montant individuel, aucune dépense par poste. Le titre reprend le prénom et le nom de la personne décédée (« Cotisations pour Jean Ndong »), pour que le message se comprenne dans un groupe WhatsApp ; ce n'est pas un contributeur. À confirmer dans la PR. Partage : « Copier le texte » (avec repli : sélection du texte), « Partager… » (Web Share, affiché seulement si le navigateur le propose, détecté après le montage) et « Ouvrir dans WhatsApp » (`shareHref` du parcours, lien `wa.me`). Pas de PDF, pas de lien public (hors lot 2).
- **État « clôturé » ailleurs :** Cotisations (avis « clôturées depuis le … » avec lien vers le bilan ; plus aucun formulaire ni bouton d'annulation ; le réglage de visibilité reste), Postes (avis ; plus de modification, de création ni de choix du scénario ; le scénario retenu s'affiche en lecture), carte du tableau de bord (« Cotisations clôturées le … » et lien « Voir le bilan »).
- **Hors PR :** PDF, lien public vers le bilan, suppression d'un dossier qui a un registre, nettoyage de la photo d'un reçu préparé avant la clôture (l'envoi reste possible sur ce chemin, mais le rattachement est refusé : la photo reste illisible des membres), suppression de reçus.

```ts
import { randomUUID } from 'node:crypto';
import type { PGlite } from '@electric-sql/pglite';
import { afterAll, beforeAll, describe, expect, it } from 'vitest';
import { asRole, asUser, createTestDb, createUser } from './helpers/db';

let db: PGlite;
let owner: string;
let coordinator: string;
let treasurer: string;
let contributor: string;
let viewer: string;
let stranger: string;

const DENIED = { code: '42501' };
const CLOSED = { code: 'TL009' };

async function createDossier(userId: string) {
  const { rows } = await asUser(db, userId, () =>
    db.query<{ id: string }>(
      `select public.create_dossier_with_person('death', 'Jean', 'Ndong', 'GA', 'Libreville', '') as id`,
    ),
  );
  return rows[0]!.id;
}

/** Dossier neuf du propriétaire, avec un membre de chaque rôle. */
async function freshDossier() {
  const id = await createDossier(owner);
  const roles: [string, string][] = [
    [coordinator, 'coordinator'],
    [treasurer, 'treasurer'],
    [contributor, 'contributor'],
    [viewer, 'viewer'],
  ];
  for (const [user, role] of roles) {
    await db.query(`insert into dossier_member (dossier_id, user_id, role) values ($1, $2, $3)`, [
      id,
      user,
      role,
    ]);
  }
  return id;
}

const close = (userId: string, dossier: string) =>
  asUser(db, userId, () =>
    db.query<{ closed_at: Date }>('select public.close_ledger($1) as closed_at', [dossier]),
  );

const reopen = (userId: string, dossier: string) =>
  asUser(db, userId, () => db.query('select public.reopen_ledger($1)', [dossier]));

async function closure(dossier: string) {
  const { rows } = await db.query<{ closed_at: Date | null; closed_by: string | null }>(
    'select closed_at, closed_by from dossier_finance where dossier_id = $1',
    [dossier],
  );
  return rows[0] ?? { closed_at: null, closed_by: null };
}

async function events(dossier: string) {
  const { rows } = await db.query<{ action: string; actor_id: string | null }>(
    `select action, actor_id from ledger_closure_event where dossier_id = $1
      order by created_at, action`,
    [dossier],
  );
  return rows;
}

async function addEntry(
  userId: string,
  dossier: string,
  kind: 'pledge' | 'receipt' | 'expense' = 'receipt',
  key: string = randomUUID(),
) {
  const { rows } = await asUser(db, userId, () =>
    db.query<{ id: string }>(
      `insert into ledger_entry (dossier_id, kind, amount, method, party_name, member_id, idempotency_key)
       values ($1, $2, 10000, $3, 'Oncle Paul', $4, $5) returning id`,
      [dossier, kind, kind === 'pledge' ? null : 'cash', kind === 'pledge' ? userId : null, key],
    ),
  );
  return rows[0]!.id;
}

const reverse = (userId: string, dossier: string, entryId: string) =>
  asUser(db, userId, () =>
    db.query(
      `insert into ledger_entry (dossier_id, kind, amount, party_name, reverses_id, idempotency_key)
       values ($1, 'reversal', 1, '-', $2, $3)`,
      [dossier, entryId, randomUUID()],
    ),
  );

async function addLine(userId: string, dossier: string) {
  const { rows } = await asUser(db, userId, () =>
    db.query<{ id: string }>(
      `insert into budget_line (dossier_id, label) values ($1, 'Fleurs') returning id`,
      [dossier],
    ),
  );
  return rows[0]!.id;
}

async function prepareReceipt(userId: string, dossier: string) {
  const { rows } = await asUser(db, userId, () =>
    db.query<{ id: string; storage_path: string }>(
      `insert into receipt (dossier_id, mime_type, size_bytes) values ($1, 'image/jpeg', 1000)
       returning id, storage_path`,
      [dossier],
    ),
  );
  return rows[0]!;
}

beforeAll(async () => {
  db = await createTestDb();
  owner = await createUser(db, 'owner@test.local');
  coordinator = await createUser(db, 'coordinator@test.local');
  treasurer = await createUser(db, 'treasurer@test.local');
  contributor = await createUser(db, 'contributor@test.local');
  viewer = await createUser(db, 'viewer@test.local');
  stranger = await createUser(db, 'stranger@test.local');
});

afterAll(async () => {
  await db?.close();
});

describe('close_ledger', () => {
  it('clôture par un trésorier, une seule fois, et le journalise', async () => {
    const id = await freshDossier();
    const first = await close(treasurer, id);
    const state = await closure(id);
    expect(state.closed_by).toBe(treasurer);
    expect(state.closed_at).not.toBeNull();
    // WHY: une seconde clôture (double clic, autre trésorier) garde la date et l'auteur.
    const second = await close(coordinator, id);
    expect(new Date(second.rows[0]!.closed_at).getTime()).toBe(
      new Date(first.rows[0]!.closed_at).getTime(),
    );
    expect((await closure(id)).closed_by).toBe(treasurer);
    expect(await events(id)).toEqual([{ action: 'close', actor_id: treasurer }]);
  });

  it('refuse un contributeur, un lecteur, un non-membre, un visiteur et une session sans utilisateur', async () => {
    const id = await freshDossier();
    for (const user of [contributor, viewer, stranger]) {
      await expect(close(user, id)).rejects.toMatchObject(DENIED);
    }
    await expect(
      asRole(db, 'anon', null, () => db.query('select public.close_ledger($1)', [id])),
    ).rejects.toMatchObject(DENIED);
    await expect(
      asRole(db, 'authenticated', null, () => db.query('select public.close_ledger($1)', [id])),
    ).rejects.toMatchObject({ code: '28000' });
    expect((await closure(id)).closed_at).toBeNull();
  });
});

describe('reopen_ledger', () => {
  it('rouvre par le propriétaire seul et le journalise', async () => {
    const id = await freshDossier();
    await close(treasurer, id);
    for (const user of [treasurer, coordinator]) {
      await expect(reopen(user, id)).rejects.toMatchObject(DENIED);
    }
    await reopen(owner, id);
    expect(await closure(id)).toEqual({ closed_at: null, closed_by: null });
    expect(await events(id)).toEqual([
      { action: 'close', actor_id: treasurer },
      { action: 'reopen', actor_id: owner },
    ]);
  });

  it('ne fait rien sur un dossier ouvert', async () => {
    const id = await freshDossier();
    await reopen(owner, id);
    expect(await events(id)).toEqual([]);
  });
});

describe('colonnes et journal de clôture', () => {
  it('ne laisse écrire la clôture et le journal que par les fonctions', async () => {
    const id = await freshDossier();
    await close(treasurer, id);
    await expect(
      asUser(db, owner, () =>
        db.query('update dossier_finance set closed_at = null where dossier_id = $1', [id]),
      ),
    ).rejects.toMatchObject(DENIED);
    await expect(
      asUser(db, owner, () =>
        db.query('update dossier_finance set closed_by = $2 where dossier_id = $1', [id, owner]),
      ),
    ).rejects.toMatchObject(DENIED);
    const other = await freshDossier();
    await expect(
      asUser(db, owner, () =>
        db.query('insert into dossier_finance (dossier_id, closed_at) values ($1, now())', [other]),
      ),
    ).rejects.toMatchObject(DENIED);
    await expect(
      asUser(db, owner, () =>
        db.query(`insert into ledger_closure_event (dossier_id, action) values ($1, 'close')`, [
          id,
        ]),
      ),
    ).rejects.toMatchObject(DENIED);
  });

  it('garde le réglage de visibilité modifiable par le propriétaire, même clôturé', async () => {
    const id = await freshDossier();
    await close(treasurer, id);
    // WHY: requête de l'upsert de PostgREST (supabase-js), qui réécrit aussi dossier_id.
    await asUser(db, owner, () =>
      db.query(
        `insert into dossier_finance (dossier_id, amounts_visibility) values ($1, 'members')
         on conflict (dossier_id) do update
           set dossier_id = excluded.dossier_id, amounts_visibility = excluded.amounts_visibility`,
        [id],
      ),
    );
    const { rows } = await db.query<{ amounts_visibility: string }>(
      'select amounts_visibility from dossier_finance where dossier_id = $1',
      [id],
    );
    expect(rows[0]?.amounts_visibility).toBe('members');
    expect((await closure(id)).closed_by).toBe(treasurer);
  });

  it('ouvre le journal au trésorier et plus, pas aux autres membres', async () => {
    const id = await freshDossier();
    await close(treasurer, id);
    const count = async (user: string) =>
      (
        await asUser(db, user, () =>
          db.query('select id from ledger_closure_event where dossier_id = $1', [id]),
        )
      ).rows.length;
    expect(await count(treasurer)).toBe(1);
    expect(await count(owner)).toBe(1);
    expect(await count(contributor)).toBe(0);
    expect(await count(viewer)).toBe(0);
    expect(await count(stranger)).toBe(0);
  });

  it('laisse lire les totaux d’un dossier clôturé', async () => {
    const id = await freshDossier();
    await addEntry(treasurer, id, 'receipt');
    await close(treasurer, id);
    const { rows } = await asUser(db, viewer, () =>
      db.query<{ received: number | string }>('select received from public.ledger_totals($1)', [
        id,
      ]),
    );
    expect(Number(rows[0]!.received)).toBe(10_000);
  });
});

describe('écritures refusées une fois clôturé', () => {
  it('refuse toute ligne du registre, annulations et promesses comprises', async () => {
    const id = await freshDossier();
    const key = randomUUID();
    const entry = await addEntry(treasurer, id, 'receipt', key);
    await close(treasurer, id);
    await expect(addEntry(treasurer, id, 'receipt')).rejects.toMatchObject(CLOSED);
    await expect(addEntry(treasurer, id, 'expense')).rejects.toMatchObject(CLOSED);
    await expect(addEntry(contributor, id, 'pledge')).rejects.toMatchObject(CLOSED);
    await expect(reverse(treasurer, id, entry)).rejects.toMatchObject(CLOSED);
    // WHY: le rejeu d'une ligne déjà enregistrée reste un double envoi (23505), pour que le dépôt
    // renvoie la ligne existante.
    await expect(addEntry(treasurer, id, 'receipt', key)).rejects.toMatchObject({
      code: '23505',
    });
    // WHY: le rôle est vérifié avant la clôture : un non-membre ou un lecteur ne sonde pas l'état.
    await expect(addEntry(stranger, id, 'receipt')).rejects.toMatchObject(DENIED);
    await expect(addEntry(viewer, id, 'pledge')).rejects.toMatchObject(DENIED);
  });

  it('refuse de créer, modifier ou supprimer un poste, et de changer le scénario', async () => {
    const id = await freshDossier();
    const line = await addLine(treasurer, id);
    await close(treasurer, id);
    await expect(addLine(treasurer, id)).rejects.toMatchObject(CLOSED);
    await expect(
      asUser(db, treasurer, () =>
        db.query(`update budget_line set label = 'Gerbes' where id = $1`, [line]),
      ),
```

```sql
-- ---------------------------------------------------------------------------
-- Contrôle commun : refuse une écriture financière sur un dossier clôturé.
-- ---------------------------------------------------------------------------
-- WHY: security definer pour lire dossier_finance et verrouiller le dossier quelle que soit la
-- RLS de l'appelant ; non exécutable via l'API (seuls les triggers et set_budget_scenario
-- l'appellent, en tant que propriétaire des fonctions) ; search_path vide contre le
-- détournement de schéma.
create function public.ledger_assert_open(p_dossier_id uuid)
returns void
language plpgsql
security definer
set search_path = ''
as $$
begin
  -- WHY: verrou partagé sur la ligne du dossier, en face du verrou exclusif (« for no key
  -- update ») de close_ledger et reopen_ledger : une écriture en cours finit avant la clôture, et
  -- une écriture qui suit la clôture la voit (nouvelle lecture après l'attente). Les écritures
  -- entre elles ne se bloquent pas (verrous partagés compatibles).
  perform 1 from public.dossier d where d.id = p_dossier_id for share;
  -- WHY: dossier introuvable : suppression en cascade en cours (la ligne du dossier n'est déjà
  -- plus visible), rien à protéger. Une insertion vers un dossier absent est refusée ailleurs
  -- (rôle, clé étrangère).
  if not found then
    return;
  end if;
  if exists (
    select 1 from public.dossier_finance f
     where f.dossier_id = p_dossier_id and f.closed_at is not null
  ) then
    raise exception 'ledger closed' using errcode = 'TL009';
  end if;
end;
$$;

revoke execute on function public.ledger_assert_open(uuid) from public, anon, authenticated;

-- ---------------------------------------------------------------------------
-- Clôture et réouverture.
-- ---------------------------------------------------------------------------
create function public.close_ledger(p_dossier_id uuid)
returns timestamptz
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_closed_at timestamptz;
begin
  if auth.uid() is null then
    raise exception 'not authenticated' using errcode = '28000';
  end if;
  if not public.is_dossier_member(p_dossier_id, 'treasurer') then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  -- WHY: verrou exclusif sur le dossier (voir ledger_assert_open) ; deux clôtures simultanées
  -- se suivent.
  perform 1 from public.dossier d where d.id = p_dossier_id for no key update;
  select f.closed_at into v_closed_at
    from public.dossier_finance f
   where f.dossier_id = p_dossier_id;
  -- WHY: clôturer un dossier déjà clôturé est sans effet (double clic, deux trésoriers) : la date
  -- et l'auteur de la première clôture restent, aucun événement n'est journalisé.
  if v_closed_at is not null then
    return v_closed_at;
  end if;
  v_closed_at := now();
  insert into public.dossier_finance (dossier_id, closed_at, closed_by)
  values (p_dossier_id, v_closed_at, auth.uid())
  on conflict (dossier_id) do update
    set closed_at = excluded.closed_at, closed_by = excluded.closed_by;
  insert into public.ledger_closure_event (dossier_id, action, actor_id)
  values (p_dossier_id, 'close', auth.uid());
  return v_closed_at;
end;
$$;

-- ---------------------------------------------------------------------------
-- Registre : refusé une fois clôturé (après le rôle et le rejeu).
-- ---------------------------------------------------------------------------
-- WHY: security definer pour lire la ligne visée ou la promesse quelle que soit la
-- RLS du lecteur ; search_path vide contre le détournement de schéma.
create or replace function public.ledger_entry_before_insert()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_target public.ledger_entry;
begin
  -- WHY: contrôle du rôle avant tout autre, pour qu'un non-membre ou un lecteur
  -- ne puisse pas sonder le registre par les codes TL001 à TL003 ni par TL009. La
  -- RLS reste la règle de référence.
  if not public.is_dossier_member(
    new.dossier_id,
    (case when new.kind = 'pledge' then 'contributor' else 'treasurer' end)::public.dossier_role
  ) then
    raise exception 'not allowed' using errcode = '42501';
  end if;

  -- WHY: un second envoi (même clé d'idempotence) doit donner 23505, que le dépôt traite comme
  -- un double envoi ; il ne doit pas être jugé à nouveau (par exemple TL002 une fois que la
  -- première cotisation a soldé la promesse, ou TL009 une fois le dossier clôturé). On lève
  -- 23505 ici plutôt que de laisser passer la ligne : non normalisée par la suite du trigger,
  -- elle échouerait d'abord sur une contrainte check (23514, par exemple reverses_kind d'une
  -- annulation). La contrainte d'unicité reste le garde-fou pour deux envois concurrents.
  if exists (
    select 1
      from public.ledger_entry e
     where e.dossier_id = new.dossier_id
       and e.idempotency_key = new.idempotency_key
  ) then
    raise exception 'duplicate idempotency key' using errcode = '23505';
  end if;

  perform public.ledger_assert_open(new.dossier_id);

  new.created_by := auth.uid();
  new.created_at := now();

  if new.occurred_on > current_date + 1 then
    raise exception 'invalid date' using errcode = '23514';
  end if;

  if new.kind = 'reversal' then
    -- WHY: verrou sur la ligne visée, pour sérialiser une annulation et un
    -- versement concurrents qui la concernent.
    select * into v_target from public.ledger_entry where id = new.reverses_id for update;
    if not found or v_target.dossier_id <> new.dossier_id or v_target.kind = 'reversal' then
      raise exception 'invalid reversal' using errcode = 'TL001';
    end if;
    new.amount := v_target.amount;
    new.party_name := v_target.party_name;
    new.member_id := v_target.member_id;
    new.reverses_kind := v_target.kind;
    new.method := null;
    new.pledge_id := null;
    new.budget_line_id := null;
    return new;
  end if;
  new.reverses_kind := null;
  -- WHY: le poste d'une dépense doit appartenir au même dossier. Pour les autres
  -- types, la contrainte check sur budget_line_id refuse la ligne (23514).
  if new.kind = 'expense' and new.budget_line_id is not null and not exists (
    select 1 from public.budget_line l
     where l.id = new.budget_line_id and l.dossier_id = new.dossier_id
  ) then
    raise exception 'invalid budget line' using errcode = 'TL004';
  end if;

  -- WHY: seule une cotisation reçue peut viser une promesse ; pour les autres types,
  -- la contrainte check sur pledge_id refuse la ligne (23514).
  if new.pledge_id is not null and new.kind = 'receipt' then
    -- WHY: verrou sur la promesse avant de compter ses versements : deux cotisations
    -- concurrentes sur la même promesse se sérialisent sur ce verrou, la seconde
    -- voit donc la première.
    select * into v_target from public.ledger_entry where id = new.pledge_id for update;
    if not found
      or v_target.dossier_id <> new.dossier_id
      or v_target.kind <> 'pledge'
      or exists (select 1 from public.ledger_entry r where r.reverses_id = v_target.id)
      or (
        select coalesce(sum(rc.amount), 0)
          from public.ledger_entry rc
         where rc.pledge_id = v_target.id
           and rc.kind = 'receipt'
           and not exists (select 1 from public.ledger_entry rv where rv.reverses_id = rc.id)
      ) >= v_target.amount
    then
      raise exception 'invalid pledge' using errcode = 'TL002';
    end if;
    -- WHY: le membre qui a promis doit voir sa cotisation, même en mode restreint.
    new.member_id := v_target.member_id;
  end if;

  -- WHY: un versement lié à une promesse reprend le membre de la promesse, même si
  -- ce membre a quitté le dossier depuis : la somme promise reste due.
  if new.pledge_id is null and new.member_id is not null and not exists (
    select 1 from public.dossier_member m
     where m.dossier_id = new.dossier_id and m.user_id = new.member_id
  ) then
    raise exception 'invalid member' using errcode = 'TL003';
  end if;
  return new;
end;
$$;

revoke execute on function public.ledger_entry_before_insert() from public, anon, authenticated;

security definer

begin
  -- WHY: contrôle du rôle avant le comptage et la clôture, pour qu'un non-membre ne puisse pas

-- ---------------------------------------------------------------------------
-- Reçus : préparation et rattachement refusés une fois clôturé.
-- ---------------------------------------------------------------------------
-- WHY: security definer pour compter les reçus du dossier quelle que soit la RLS du lecteur ;
-- search_path vide contre le détournement de schéma.
create or replace function public.receipt_before_insert()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
begin
  -- WHY: contrôle du rôle avant le comptage et la clôture, pour qu'un non-membre ne puisse pas
  -- sonder le dossier par TL007 ou TL009. La RLS reste la règle de référence.
  if not public.is_dossier_member(new.dossier_id, 'treasurer') then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  -- WHY: deux préparations concurrentes compteraient chacune 199 reçus ; le verrou sur la ligne
  -- du dossier les sérialise (« for no key update » ne bloque pas les clés étrangères).
  perform 1 from public.dossier d where d.id = new.dossier_id for no key update;
  perform public.ledger_assert_open(new.dossier_id);
  -- WHY: les préparations abandonnées (photo jamais envoyée ou dépense jamais enregistrée) ne
  -- doivent pas épuiser la limite, puisqu'aucune suppression n'est possible : on ne compte que les
  -- reçus rattachés et les non rattachés de moins de 24 heures.
  if (
    select count(*) from public.receipt r
     where r.dossier_id = new.dossier_id
       and (r.entry_id is not null or r.created_at > now() - interval '24 hours')
  ) >= 200 then
    raise exception 'too many receipts' using errcode = 'TL007';
  end if;
  new.entry_id := null;
  new.created_by := auth.uid();
  new.created_at := now();
  -- WHY: « bin » pour un type inconnu : la contrainte check sur mime_type refuse alors la ligne
  -- (23514) au lieu d'un chemin nul (23502).
  new.storage_path := new.dossier_id::text || '/' || new.id::text || '.' || (
    case new.mime_type
      when 'image/jpeg' then 'jpg'
      when 'image/png' then 'png'
      when 'image/webp' then 'webp'
      else 'bin'
    end
  );
  return new;
end;
$$;

-- WHY: tout est figé sauf entry_id ; un rattachement va vers une dépense du même dossier et
-- ne change plus ensuite (le même rattachement rejoué est sans effet, même clôturé). Codes pour
-- que l'application sache s'il faut réessayer : TL006 (photo pas encore au stockage) peut
-- réussir plus tard, TL008 (déjà rattaché ailleurs, détachement, ligne invalide) est définitif,
-- TL009 : dossier clôturé. Security definer pour lire storage.objects quelle que soit la RLS du
-- stockage ; search_path vide contre le détournement.
create or replace function public.receipt_before_update()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
begin
  new.id := old.id;
  new.dossier_id := old.dossier_id;
  new.storage_path := old.storage_path;
  new.mime_type := old.mime_type;
  new.size_bytes := old.size_bytes;
  new.created_by := old.created_by;
  new.created_at := old.created_at;
  if old.entry_id is not null and new.entry_id is distinct from old.entry_id then
    raise exception 'receipt already attached' using errcode = 'TL008';
  end if;
  if old.entry_id is null and new.entry_id is not null then
    perform public.ledger_assert_open(old.dossier_id);
  end if;
  -- WHY: une dépense annulée (ligne « reversal ») reste une dépense : le rattachement est
  -- accepté, car la photo justifie la ligne d'origine.
  if old.entry_id is null and new.entry_id is not null and not exists (
    select 1 from public.ledger_entry e
     where e.id = new.entry_id and e.dossier_id = new.dossier_id and e.kind = 'expense'
  ) then
    raise exception 'invalid receipt link' using errcode = 'TL008';
  end if;
  -- WHY: le lien d'envoi signé de Supabase reste valide 2 heures et la policy d'envoi n'est pas
  -- réévaluée au moment de l'envoi : on exige donc la photo au stockage avant le rattachement,
  -- pour qu'aucune photo n'arrive sur le chemin d'un reçu déjà rattaché. Le stockage de production
  -- est versionné : seule la version courante (non archivée) compte.
  if old.entry_id is null and new.entry_id is not null and not exists (
    select 1 from storage.objects o
     where o.bucket_id = 'receipts' and o.name = old.storage_path and o.archived_at is null
  ) then
    raise exception 'receipt photo missing' using errcode = 'TL006';
  end if;
  return new;
end;
$$;

revoke execute on function public.receipt_before_insert() from public, anon, authenticated;
revoke execute on function public.receipt_before_update() from public, anon, authenticated;
```

```ts
import 'server-only';
import { getSupabaseServer } from '@/lib/supabase/server';
import type { RepoResult } from '@/modules/dossier/repo';
import type { EntryKind, EntryMethod } from '../ledger/schema';
import type { Closure, ExportRow } from './schema';

/** Taille d'une page de lecture : le plafond par défaut de PostgREST chez Supabase. */
const PAGE = 1000;

/**
 * Au plus 50 000 lignes exportées.
 * WHY: au-delà, l'export est refusé (`too_large`) plutôt que tronqué : un fichier incomplet
 * tromperait la famille.
 */
export const EXPORT_MAX_ROWS = 50_000;

const EXPORT_COLUMNS =
  'id, kind, amount, method, party_name, budget_line_id, note, occurred_on, reverses_id, created_at';

interface ExportDbRow {
  id: string;
  kind: EntryKind;
  amount: number | string;
  method: EntryMethod | null;
  party_name: string;
  budget_line_id: string | null;
  note: string;
  occurred_on: string;
  reverses_id: string | null;
  created_at: string;
}

const toRow = (r: ExportDbRow): ExportRow => ({
  id: r.id,
  kind: r.kind,
  amount: Number(r.amount),
  method: r.method,
  partyName: r.party_name,
  budgetLineId: r.budget_line_id,
  note: r.note,
  occurredOn: r.occurred_on,
  reversesId: r.reverses_id,
  createdAt: r.created_at,
});

function fail(error: { code?: string; message?: string }) {
  return {
    data: null,
    error: { code: error.code || 'unknown', message: error.message || 'closing error' },
  };
}

/**
 * État de clôture des cotisations (tout membre, RLS) ; ouvertes tant que rien n'est réglé.
 *
 * @example
 * const { data } = await getClosure(dossierId); // { closedAt: '2026-10-28T09:00:00Z' }
 */
export async function getClosure(dossierId: string): Promise<RepoResult<Closure>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('dossier_finance')
    .select('closed_at')
    .eq('dossier_id', dossierId)
    .maybeSingle<{ closed_at: string | null }>();
  if (error) {
    console.error('[budget/closing] getClosure impossible', { code: error.code });
    return fail(error);
  }
  return { data: { closedAt: data?.closed_at ?? null }, error: null };
}

/** Clôture les cotisations (trésorier et plus, vérifié par la base) ; renvoie la date de clôture. */
export async function closeLedger(dossierId: string): Promise<RepoResult<string>> {
  const db = await getSupabaseServer();
  const { data, error } = await db.rpc('close_ledger', { p_dossier_id: dossierId });
  if (error) return fail(error);
  return { data: String(data), error: null };
}

/** Rouvre les cotisations (propriétaire seul, vérifié par la base). */
export async function reopenLedger(dossierId: string): Promise<RepoResult<true>> {
  const db = await getSupabaseServer();
  const { error } = await db.rpc('reopen_ledger', { p_dossier_id: dossierId });
  if (error) return fail(error);
  return { data: true, error: null };
}

/**
 * Toutes les lignes du registre visibles (RLS), des plus anciennes aux plus récentes, par pages.
 * WHY: lu avec le client de l'utilisateur ; seul un trésorier (ou plus) voit tout, et le service
 * de l'export l'exige.
 */
export async function listExportRows(dossierId: string): Promise<RepoResult<ExportRow[]>> {
  const db = await getSupabaseServer();
  const rows: ExportRow[] = [];
  for (let from = 0; ; from += PAGE) {
    const { data, error } = await db
      .from('ledger_entry')
      .select(EXPORT_COLUMNS)
      .eq('dossier_id', dossierId)
      .order('occurred_on', { ascending: true })
      .order('created_at', { ascending: true })
      .order('id', { ascending: true })
      .range(from, from + PAGE - 1)
      .returns<ExportDbRow[]>();
    if (error) {
      console.error('[budget/closing] listExportRows impossible', { code: error.code });
      return fail(error);
    }
    rows.push(...(data ?? []).map(toRow));
    if (!data || data.length < PAGE) return { data: rows, error: null };
    if (rows.length >= EXPORT_MAX_ROWS) {
      return { data: null, error: { code: 'too_large', message: 'ledger too large to export' } };
    }
  }
}
```

```ts
import 'server-only';
import { getMyRole } from '@/modules/dossier/repo';
import { hasRole } from '@/modules/dossier/roles';
import type { DossierRole } from '@/modules/dossier/schema';
import { budgetGate } from '../gate';
import { listLines } from '../lines/repo';
import * as repo from './repo';
import { ClosingRefSchema, type ExportRow } from './schema';

export type ClosingError =
  | 'validation'
  | 'forbidden'
  | 'not_found'
  | 'unauthenticated'
  | 'too_large'
  | 'unknown';

export type ClosingResult<T> = { ok: true; data: T } | { ok: false; error: ClosingError };

/** État renvoyé par les actions de clôture et de réouverture. */
export interface ClosingFormState {
  ok?: boolean;
  error?: ClosingError;
}

/** Lignes du registre et libellés des postes, pour l'export (trésorier et plus). */
export interface LedgerExport {
  rows: ExportRow[];
  lineLabels: Map<string, string>;
}

const CODES: Record<string, ClosingError> = {
  '42501': 'forbidden',
  '28000': 'unauthenticated',
  // WHY: JWT expiré signalé par PostgREST.
  PGRST301: 'unauthenticated',
  '22P02': 'validation',
  // WHY: registre de plus de 50 000 lignes (dépôt) : refusé plutôt que tronqué.
  too_large: 'too_large',
};

function fromRepo(error: { code: string }, scope: string): { ok: false; error: ClosingError } {
  const mapped = CODES[error.code];
  if (!mapped) console.error(`[budget/closing] ${scope} failed`, { code: error.code });
  return { ok: false, error: mapped ?? 'unknown' };
}

/**
 * Porte : dossier ouvert au budget, puis rôle minimal.
 * WHY: la base revérifie le rôle (42501) ; ce contrôle donne une erreur claire sans appel inutile
 * et protège l'export, que la RLS ne ferait que réduire aux lignes visibles.
 */
async function roleGate(dossierId: string, min: DossierRole): Promise<ClosingError | null> {
  const blocked = await budgetGate(dossierId);
  if (blocked) return blocked;
  return hasRole(await getMyRole(dossierId), min) ? null : 'forbidden';
}

/**
 * Clôture les cotisations (trésorier et plus). Sans effet si elles le sont déjà : la date de la
 * première clôture est renvoyée.
 *
 * @example
 * await closeLedger({ dossierId }); // { ok: true, data: { closedAt: '2026-10-28T09:00:00Z' } }
 */
export async function closeLedger(raw: unknown): Promise<ClosingResult<{ closedAt: string }>> {
  const input = ClosingRefSchema.safeParse(raw);
  if (!input.success) return { ok: false, error: 'validation' };
  const blocked = await roleGate(input.data.dossierId, 'treasurer');
  if (blocked) return { ok: false, error: blocked };
  const res = await repo.closeLedger(input.data.dossierId);
  if (res.error) return fromRepo(res.error, 'closeLedger');
  return { ok: true, data: { closedAt: res.data } };
}

/**
 * Rouvre les cotisations (propriétaire seul). Sans effet si elles sont ouvertes.
 *
 * @example
 * await reopenLedger({ dossierId });
 */
export async function reopenLedger(raw: unknown): Promise<ClosingResult<true>> {
  const input = ClosingRefSchema.safeParse(raw);
  if (!input.success) return { ok: false, error: 'validation' };
  const blocked = await roleGate(input.data.dossierId, 'owner');
  if (blocked) return { ok: false, error: blocked };
  const res = await repo.reopenLedger(input.data.dossierId);
  if (res.error) return fromRepo(res.error, 'reopenLedger');
  return { ok: true, data: true };
}

/**
 * Registre complet et libellés des postes, pour le fichier CSV (trésorier et plus).
 * WHY: un identifiant invalide donne `not_found`, comme un dossier absent : la route répond 404.
 *
 * @example
 * const res = await exportLedger({ dossierId });
 */
export async function exportLedger(raw: unknown): Promise<ClosingResult<LedgerExport>> {
  const input = ClosingRefSchema.safeParse(raw);
  if (!input.success) return { ok: false, error: 'not_found' };
  const { dossierId } = input.data;
  const blocked = await roleGate(dossierId, 'treasurer');
  if (blocked) return { ok: false, error: blocked };
  const [rows, lines] = await Promise.all([repo.listExportRows(dossierId), listLines(dossierId)]);
  if (rows.error) return fromRepo(rows.error, 'listExportRows');
  if (lines.error) return fromRepo(lines.error, 'listLines');
  return {
    ok: true,
    data: { rows: rows.data, lineLabels: new Map(lines.data.map((l) => [l.id, l.label])) },
  };
}
```

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { getLocale } from 'next-intl/server';
import { localizedPath } from '@/lib/auth/redirect-target';
import { getCurrentUser } from '@/lib/supabase/server';
import * as service from './service';
import type { ClosingError, ClosingFormState } from './service';

/** Écrans qui affichent l'état de clôture. */
const PAGES = ['', '/cotisations', '/cotisations/postes', '/cotisations/bilan'];

async function done(
  dossierId: string,
  res: { ok: true } | { ok: false; error: ClosingError },
): Promise<ClosingFormState> {
  if (!res.ok) return { error: res.error };
  const locale = await getLocale();
  for (const page of PAGES) revalidatePath(localizedPath(`/dossier/${dossierId}${page}`, locale));
  return { ok: true };
}

/** Clôture les cotisations du dossier. */
export async function closeLedgerAction(
  _prev: ClosingFormState | null,
  formData: FormData,
): Promise<ClosingFormState> {
  if (!(await getCurrentUser())) return { error: 'unauthenticated' };
  const dossierId = String(formData.get('dossierId') ?? '');
  return done(dossierId, await service.closeLedger({ dossierId }));
}

/** Rouvre les cotisations du dossier. */
export async function reopenLedgerAction(
  _prev: ClosingFormState | null,
  formData: FormData,
): Promise<ClosingFormState> {
  if (!(await getCurrentUser())) return { error: 'unauthenticated' };
  const dossierId = String(formData.get('dossierId') ?? '');
  return done(dossierId, await service.reopenLedger({ dossierId }));
}
```

```ts
import type { ClosingError } from '../service';

/** Erreurs propres à la clôture, traduites dans `closing.errors` ; les autres dans `dossier.errors`. */
const CLOSING_SPECIFIC: ReadonlySet<ClosingError> = new Set(['too_large']);

/**
 * Texte d'une erreur de la clôture, à partir d'un traducteur sans espace de noms.
 *
 * @example
 * const t = useTranslations();
 * closingErrorText('forbidden', (key) => t(key)); // « Vous n'avez pas les droits… »
 */
export function closingErrorText(error: ClosingError, t: (key: string) => string): string {
  return t(CLOSING_SPECIFIC.has(error) ? `closing.errors.${error}` : `dossier.errors.${error}`);
}
```

```ts
import { hasRole } from '@/modules/dossier/roles';
import type { DossierRole } from '@/modules/dossier/schema';
import { balance, remaining, type EntryView, type LedgerTotals } from '../ledger/model';
import type { Visibility } from '../ledger/schema';
import type { ReferenceBudget } from '../lines/model';

/** Traducteur de l'espace `closing.share`. */
export type Translate = (key: string, values?: Record<string, string>) => string;

/** Ce que le texte de synthèse peut dire : des totaux, jamais une ligne individuelle. */
export interface SummaryInput {
  /** Prénom et nom de la personne décédée, ou null. */
  name: string | null;
  budget: ReferenceBudget | null;
  totals: LedgerTotals;
  /** Date de clôture déjà formatée, ou null si les cotisations sont ouvertes. */
  closedOn: string | null;
}

const LEDGER_TIME_ZONE = 'Africa/Libreville';

/**
 * Texte de bilan à partager (WhatsApp, SMS, e-mail).
 * WHY: construit à partir des totaux, visibles de tout membre (`ledger_totals`) : aucun nom de
 * contributeur, aucun montant individuel, aucune dépense par poste.
 *
 * @example
 * summaryText({ name: 'Jean Ndong', budget, totals, closedOn: '28 octobre 2026' }, t, money);
 */
export function summaryText(
  input: SummaryInput,
  t: Translate,
  money: (amount: number) => string,
): string {
  const { budget, totals } = input;
  const rest = remaining(budget?.amount ?? null, totals);
  const lines = [
    input.name ? t('heading', { name: input.name }) : t('headingNoName'),
    '',
    ...(budget
      ? [
          t(budget.source === 'retained' ? 'budgetRetained' : 'budget', {
            amount: money(budget.amount),
          }),
        ]
      : []),
    t('received', { amount: money(totals.received) }),
    t('pledgedOpen', { amount: money(totals.pledgedOpen) }),
    t('spent', { amount: money(totals.spent) }),
    t('balance', { amount: money(balance(totals)) }),
    ...(rest === null ? [] : [t('remaining', { amount: money(rest) })]),
    '',
    input.closedOn ? t('closed', { date: input.closedOn }) : t('provisional'),
  ];
  return lines.join('\n');
}

/**
 * Cotisations reçues actives parmi les lignes visibles (la RLS a déjà appliqué la visibilité).
 *
 * @example
 * receivedContributions(entryViews(entries)); // [{ kind: 'receipt', reversed: false, … }]
 */
export function receivedContributions(views: readonly EntryView[]): EntryView[] {
  return views.filter((v) => v.kind === 'receipt' && !v.reversed);
}

/**
 * La personne voit-elle les montants de tous les cotisants ?
 * WHY: même règle que la RLS du registre ; sert seulement au titre de la liste.
 */
export function seesAllAmounts(role: DossierRole | null, visibility: Visibility): boolean {
  if (role === null) return false;
  return hasRole(role, 'treasurer') || visibility === 'members';
}

/**
 * Date de clôture lisible, dans le fuseau du registre.
 *
 * @example
 * formatClosedOn('2026-10-28T09:00:00Z', 'fr'); // « 28 octobre 2026 »
 */
export function formatClosedOn(iso: string, locale: string): string {
```

```ts
import type { EntryKind, EntryMethod } from '../ledger/schema';
import type { ExportRow } from './schema';

/** Colonnes de l'export du registre, dans l'ordre du fichier. */
export const CSV_COLUMNS = [
  'date',
  'kind',
  'amount',
  'method',
  'party',
  'line',
  'note',
  'reverses',
  'id',
  'createdAt',
] as const;
export type CsvColumn = (typeof CSV_COLUMNS)[number];

/** Libellés traduits de l'en-tête, des types de ligne et des moyens de paiement. */
export interface CsvLabels {
  columns: Record<CsvColumn, string>;
  kind: Record<EntryKind, string>;
  method: Record<EntryMethod, string>;
}

// WHY: « ; » est le séparateur attendu par les tableurs réglés en français ; le BOM fait lire
// l'UTF-8 (accents) à Excel.
const SEPARATOR = ';';
const BOM = '﻿';

// WHY: une cellule qui commence par =, +, -, @, tabulation ou retour chariot serait exécutée
// comme une formule par un tableur (injection CSV) ; on la préfixe d'une apostrophe.
const FORMULA_START = /^[=+\-@\t\r]/;

function cell(value: string): string {
  const safe = FORMULA_START.test(value) ? `'${value}` : value;
  return `"${safe.replace(/"/g, '""')}"`;
}

/**
 * Registre complet au format CSV : une ligne par mouvement, annulations comprises, montants
 * entiers en XAF.
 *
 * @example
 * ledgerCsv(rows, new Map([[lineId, 'Cercueil']]), labels); // '﻿"Date";"Type";…\r\n…'
 */
export function ledgerCsv(
  rows: readonly ExportRow[],
  lineLabels: ReadonlyMap<string, string>,
  labels: CsvLabels,
): string {
  const header = CSV_COLUMNS.map((column) => cell(labels.columns[column])).join(SEPARATOR);
  const body = rows.map((r) =>
    [
      r.occurredOn,
      labels.kind[r.kind],
      String(r.amount),
      r.method ? labels.method[r.method] : '',
      r.partyName,
      r.budgetLineId ? (lineLabels.get(r.budgetLineId) ?? '') : '',
      r.note,
      r.reversesId ?? '',
      r.id,
      r.createdAt,
    ]
      .map(cell)
      .join(SEPARATOR),
  );
  return `${BOM}${[header, ...body].join('\r\n')}\r\n`;
}
```

```ts
import 'server-only';
import { getTranslations } from 'next-intl/server';
import { getCurrentUser } from '@/lib/supabase/server';
import { ENTRY_KINDS, ENTRY_METHODS, ledgerToday } from '../ledger/schema';
import { CSV_COLUMNS, ledgerCsv, type CsvLabels } from './csv';
import { ExportLangSchema } from './schema';
import { exportLedger, type ClosingError } from './service';

const NO_STORE = { 'Cache-Control': 'no-store' };

// WHY: absent, interdit et invalide donnent 404, pour ne pas révéler l'existence d'un dossier.
const STATUS: Record<ClosingError, number> = {
  validation: 404,
  forbidden: 404,
  not_found: 404,
  unauthenticated: 401,
  too_large: 413,
  unknown: 502,
};

/**
 * Réponse de « Télécharger le registre (CSV) » : session exigée, trésorier et plus.
 * WHY: le fichier est produit à la demande avec le client de l'utilisateur (RLS), jamais
 * service-role, et n'est jamais mis en cache.
 *
 * @example
 * export async function GET(req, { params }) {
 *   return ledgerExportResponse((await params).dossierId, new URL(req.url).searchParams.get('lang'));
 * }
 */
export async function ledgerExportResponse(
  dossierId: string,
  lang: string | null,
): Promise<Response> {
  if (!(await getCurrentUser())) return new Response(null, { status: 401, headers: NO_STORE });
  const res = await exportLedger({ dossierId });
  if (!res.ok) return new Response(null, { status: STATUS[res.error], headers: NO_STORE });

  const locale = ExportLangSchema.parse(lang ?? undefined);
  const [t, tKind, tMethod] = await Promise.all([
    getTranslations({ locale, namespace: 'closing.export' }),
    getTranslations({ locale, namespace: 'ledger.kind' }),
    getTranslations({ locale, namespace: 'ledger.method' }),
  ]);
  const labels: CsvLabels = {
    columns: Object.fromEntries(
      CSV_COLUMNS.map((column) => [column, t(`columns.${column}`)]),
    ) as CsvLabels['columns'],
    kind: Object.fromEntries(ENTRY_KINDS.map((k) => [k, tKind(k)])) as CsvLabels['kind'],
    method: Object.fromEntries(ENTRY_METHODS.map((m) => [m, tMethod(m)])) as CsvLabels['method'],
  };
  return new Response(ledgerCsv(res.data.rows, res.data.lineLabels, labels), {
    status: 200,
    headers: {
      'Content-Type': 'text/csv; charset=utf-8',
      'Content-Disposition': `attachment; filename="${t('fileName')}-${ledgerToday()}.csv"`,
      'X-Content-Type-Options': 'nosniff',
      ...NO_STORE,
    },
  });
}
```

```tsx
  startTransition,
  useActionState,
  useCallback,
  useEffect,
  useId,

  useState,

import type { FormEvent } from 'react';
import { useTranslations } from 'next-intl';
import { buttonClasses } from '@/components/ui/Button';
import { closeLedgerAction, reopenLedgerAction } from '../actions';
import type { ClosingFormState } from '../service';

interface Props {
  dossierId: string;
  closed: boolean;
  /** Propriétaire du dossier : seul à pouvoir rouvrir. */
  canReopen: boolean;
}

type Action = (prev: ClosingFormState | null, data: FormData) => Promise<ClosingFormState>;

/** État d'une action de clôture, envoi par onSubmit, rappel en cas de succès. */
function useClosingForm(action: Action, onDone: () => void) {
  const [state, formAction, pending] = useActionState<ClosingFormState | null, FormData>(
    action,
    null,
  );
  useEffect(() => {
    if (state?.ok) onDone();
  }, [state, onDone]);
  // WHY: onSubmit plutôt que `<form action>` : React 19 réinitialise le formulaire après chaque
  // action, même en erreur.
  const onSubmit = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (pending) return;
    const data = new FormData(e.currentTarget);
    startTransition(() => formAction(data));
  };
  return { state, pending, onSubmit };
}

/** Clôture en deux temps (clôturer, puis confirmer), avec l'avertissement. */
function CloseForm({ dossierId, onDone }: { dossierId: string; onDone: () => void }) {
  const t = useTranslations('closing.control');
  const tAll = useTranslations();
  const [confirming, setConfirming] = useState(false);
  const { state, pending, onSubmit } = useClosingForm(closeLedgerAction, onDone);
  const openRef = useRef<HTMLButtonElement>(null);
  const keepRef = useRef<HTMLButtonElement>(null);
  const returnFocus = useRef(false);
  const warningId = useId();

  // WHY: le focus suit l'ouverture, sur le choix sans risque (« Garder ouvert »), et revient au
  // bouton d'ouverture quand la personne renonce.
  useEffect(() => {
    if (confirming) {
      keepRef.current?.focus();
    } else if (returnFocus.current) {
      returnFocus.current = false;
      openRef.current?.focus();
    }
  }, [confirming]);

  if (!confirming) {
    return (
      <button
        ref={openRef}
        type="button"
        onClick={() => setConfirming(true)}
        className={buttonClasses({ variant: 'secondary', size: 'md' })}
      >
        {t('close')}
      </button>
    );
  }
  return (
    <form onSubmit={onSubmit} className="space-y-3">
      <input type="hidden" name="dossierId" value={dossierId} />
      <p id={warningId} className="text-foreground text-sm">
        {t('closeWarning')}
      </p>
      <div className="flex flex-wrap items-center gap-3">
        <button
          type="submit"
          disabled={pending}
          aria-busy={pending || undefined}
          aria-describedby={warningId}
          className="bg-destructive text-destructive-foreground rounded-full px-4 py-1.5 text-sm font-semibold disabled:opacity-60"
        >
          {pending ? t('closing') : t('confirmClose')}
        </button>
        <button
          ref={keepRef}
          type="button"
          onClick={() => {
            returnFocus.current = true;
            setConfirming(false);
          }}
          className="text-foreground text-sm underline underline-offset-2"
        >
          {t('keepOpen')}
        </button>
      </div>
      {state?.error && (
        <p role="alert" className="text-destructive text-sm">
          {closingErrorText(state.error, (key) => tAll(key))}
        </p>
      )}
    </form>
  );
}

/** Réouverture par le propriétaire. */
function ReopenForm({ dossierId, onDone }: { dossierId: string; onDone: () => void }) {
  const t = useTranslations('closing.control');
  const tAll = useTranslations();
  const { state, pending, onSubmit } = useClosingForm(reopenLedgerAction, onDone);
  return (

          variant: 'secondary',
          size: 'md',
          className: 'disabled:cursor-not-allowed disabled:opacity-60',
        })}
      >
        {pending ? t('reopening') : t('reopen')}
      </button>
      {state?.error && (
        <p role="alert" className="text-destructive text-sm">
          {closingErrorText(state.error, (key) => tAll(key))}
        </p>
      )}
    </form>
  );

/**

 * @example
```

```tsx
      fieldRef.current?.focus();

      setStatus(t('copyManual'));

    try {
      await navigator.share({ text });

      // WHY: fermer la feuille de partage lève une erreur (AbortError) : rien à signaler.
```

```tsx
 *

    ...lines.filter((l) => l.spent > 0).map((l) => ({ key: l.id, label: l.label, spent: l.spent })),

  const total = rows.reduce((sum, r) => sum + r.spent, 0);
  return (
    <table aria-labelledby={labelledBy} className="w-full text-sm">

            {t('spent')}

      <tbody>
```
