# Lot 2 · PR 4 — Reçus : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** le trésorier photographie un reçu dans le formulaire de dépense ; la photo part dans un bucket privé, l'IA la lit et préremplit le montant, la date, le fournisseur et le poste ; le trésorier corrige et enregistre, et la dépense garde sa photo, visible des membres par un lien signé de 5 minutes.

**Architecture:** une migration crée la table `receipt` (chemin, auteur et rattachement imposés par la base, un reçu par dépense, au plus 200 par dossier) et le bucket privé `receipts`, dont les policies suivent la RLS de `receipt`. Un module `apps/web/src/modules/budget/receipts/` (schéma, dépôt, service, actions, redirection de lecture, écrans) prépare l'envoi signé, télécharge la photo côté serveur et appelle `readReceipt` (`apps/web/src/modules/ai/receipt.ts`), qui consomme le quota d'IA existant et n'envoie que l'image à OpenRouter. La dépense enregistrée rattache le reçu ; la liste des mouvements affiche « Voir le reçu ».

**Tech Stack:** Supabase (Postgres 17, RLS, Storage, PGlite pour les tests SQL), Next.js 15 (Server Components, server actions, route handlers), React 19, next-intl 3, Zod 3, Vitest (+ jsdom pour les composants), OpenRouter (Claude Opus 5.5, lecture d'images).

Spec : `docs/superpowers/specs/2026-10-27-lot-2-financer-design.md` (§ 1 « `receipt` et bucket `receipts` », § 2 « Reçu », § 3 « `readReceipt` », § 4 « Erreurs », « Tests », « Livraison » point 4, « Configuration » : aucune nouvelle variable, `OPENROUTER_API_KEY` sert aussi aux reçus).

## Décisions de ce plan (à valider dans la PR)

- **Chemin imposé :** le trigger d'insertion de `receipt` écrit `storage_path = <dossier_id>/<id>.<ext>` (`jpg`, `png`, `webp` selon le type), impose `created_by = auth.uid()`, `created_at = now()` et `entry_id = null`. Le navigateur ne choisit ni le chemin ni le rattachement initial ; une contrainte check vérifie la cohérence chemin, dossier, identifiant et type.
- **Préparer, envoyer, rattacher :** « préparer » crée la ligne `receipt` non rattachée et un lien d'envoi signé (`createSignedUploadUrl`). La durée de ce lien est fixée par Supabase (2 heures, non réglable) ; il ne sert qu'une fois, car le bucket n'a ni policy de mise à jour ni `upsert`. Le lien de **lecture**, lui, dure 5 minutes.
- **Envoi au stockage :** permis seulement sur le chemin d'un reçu préparé, pas encore rattaché, par un trésorier du dossier. La lecture d'un objet passe par la RLS de `receipt` (trésorier et plus avant rattachement, tout membre après) : une seule règle pour la ligne et la photo.
- **Rattachement :** un reçu par dépense (`entry_id` unique). Seule la colonne `entry_id` est modifiable (droit de colonne), par un trésorier, vers une dépense du même dossier, et une seule fois : un second rattachement à la même dépense est sans effet (double envoi), tout autre changement est refusé (`TL006`). Aucune suppression dans ce lot.
- **Limite :** au plus 200 reçus par dossier (`TL007`), pour borner le stockage d'un dossier ; la spec n'en fixait pas.
- **Ordre d'enregistrement :** `recordExpense` enregistre la dépense, puis rattache le reçu. Si le rattachement échoue, la dépense reste (registre en ajout seul) et l'écran affiche `receipt_unlinked` ; renvoyer le formulaire rejoue la même clé d'idempotence (la dépense existante est renvoyée) et retente le rattachement.
- **`readReceipt` reçoit l'image :** le téléchargement se fait dans `modules/budget/receipts/repo.ts` (seul accès au stockage) ; `readReceipt` consomme le quota puis appelle OpenRouter. Le service télécharge la photo et lit les postes **avant** de consommer le quota (une lecture en échec ne coûte pas d'appel), comme `improveDraft`. Le type réel est vérifié par la signature des octets, pas par le type déclaré.
- **Lecture réservée au trésorier :** `consume_ai_quota` s'ouvre dès le contributeur ; le service des reçus exige trésorier et plus avant toute lecture, comme pour la préparation.
- **Réponse de l'IA :** JSON demandé par la consigne (pas de `response_format`, dont la prise en charge varie selon le fournisseur), extrait entre la première et la dernière accolade ; chaque champ invalide devient `null` ; une réponse sans aucun champ lisible est un échec (`failed`). Le poste est proposé si la clé de grille lue correspond à un poste du dossier.
- **Préremplissage :** il ne remplace jamais un champ déjà saisi ; le moyen de paiement n'est pas lu.
- **Lecture d'une photo :** lien « Voir le reçu » vers la route `/api/receipts/[receiptId]`, qui vérifie la session, lit le reçu avec la RLS, crée un lien signé de 5 minutes et redirige (303, `no-store`, `no-referrer`). Un reçu invisible donne 404 (pas de distinction entre absent et interdit).
- **Sélecteur de fichier :** sans attribut `capture`, pour laisser le choix entre l'appareil photo et la galerie.
- **Quota :** la logique de quota d'`improveDraft` passe dans `modules/ai/quota.ts` (`takeAiQuota`), partagée avec `readReceipt` ; comportement inchangé.
- **Hors PR :** suppression de reçus, plusieurs photos par dépense, photo ajoutée à une dépense déjà enregistrée, nettoyage des photos d'un dossier supprimé (un dossier sans registre peut être supprimé : ses reçus non rattachés partent avec lui, les objets restent au stockage, illisibles), clôture et bilan (PR 5).

```sql
-- ============================================================================
-- Lot 2 · PR 4 — reçus des dépenses : table receipt et bucket privé receipts.
--
-- WHY (choix assumés) :
--  - une photo est d'abord « préparée » (ligne receipt non rattachée), puis
--    envoyée au stockage par un lien signé, puis rattachée à la dépense
--    enregistrée ;
--  - la base impose le chemin (<dossier>/<reçu>.<ext>), l'auteur, la date et
--    l'absence de rattachement à la création : le client ne choisit rien de cela ;
--  - l'envoi au stockage n'est permis que sur le chemin d'un reçu préparé et pas
--    encore rattaché, par un trésorier du dossier ;
--  - la lecture d'un objet suit la RLS de receipt : trésorier et plus pour un
--    reçu non rattaché, tout membre pour un reçu rattaché (comme les dépenses) ;
--  - un reçu par dépense ; seule la colonne entry_id se modifie, une seule fois ;
--    aucune suppression au lot 2 ;
--  - au plus 200 reçus par dossier (TL007), pour borner le stockage d'un dossier.
-- ============================================================================

create table public.receipt (
  id uuid primary key default gen_random_uuid(),
  dossier_id uuid not null references public.dossier (id) on delete cascade,
  entry_id uuid unique references public.ledger_entry (id) on delete no action,
  storage_path text not null unique,
  mime_type text not null check (mime_type in ('image/jpeg', 'image/png', 'image/webp')),
  size_bytes integer not null check (size_bytes between 1 and 5242880),
  -- WHY: nullable et « on delete set null », comme le registre : un membre peut supprimer son
  -- compte sans effacer les reçus. Le trigger l'impose à auth.uid().
  created_by uuid default auth.uid() references auth.users (id) on delete set null,
  created_at timestamptz not null default now(),
  check (
    storage_path = dossier_id::text || '/' || id::text || '.' || (
      case mime_type
        when 'image/jpeg' then 'jpg'
        when 'image/png' then 'png'
        when 'image/webp' then 'webp'
        else 'bin'
      end
    )
  )
);

create index receipt_dossier_idx on public.receipt (dossier_id, created_at desc);
create index receipt_created_by_idx on public.receipt (created_by);

-- WHY: security definer pour compter les reçus du dossier quelle que soit la RLS du lecteur ;
-- search_path vide contre le détournement de schéma.
create function public.receipt_before_insert()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
begin
  -- WHY: contrôle du rôle avant le comptage, pour qu'un non-membre ne puisse pas sonder le
  -- nombre de reçus d'un dossier par le code TL007. La RLS reste la règle de référence.
  if not public.is_dossier_member(new.dossier_id, 'treasurer') then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  -- WHY: deux préparations concurrentes compteraient chacune 199 reçus ; le verrou sur la ligne
  -- du dossier les sérialise (« for no key update » ne bloque pas les clés étrangères).
  perform 1 from public.dossier d where d.id = new.dossier_id for no key update;
  if (select count(*) from public.receipt r where r.dossier_id = new.dossier_id) >= 200 then
    raise exception 'too many receipts' using errcode = 'TL007';
  end if;
  new.entry_id := null;
  new.created_by := auth.uid();
  new.created_at := now();
  -- WHY: « bin » pour un type inconnu : la contrainte check sur mime_type refuse alors la ligne
  -- (23514) au lieu d'un chemin nul (23502).
  new.storage_path := new.dossier_id::text || '/' || new.id::text || '.' || (
    case new.mime_type
      when 'image/jpeg' then 'jpg'
      when 'image/png' then 'png'
      when 'image/webp' then 'webp'
      else 'bin'
    end
  );
  return new;
end;
$$;

create trigger receipt_before_insert
  before insert on public.receipt
  for each row execute function public.receipt_before_insert();

-- WHY: tout est figé sauf entry_id ; un rattachement va vers une dépense du même dossier et
-- ne change plus ensuite (le même rattachement rejoué est sans effet).
create function public.receipt_before_update()
returns trigger
language plpgsql
set search_path = ''
as $$
begin

  new.dossier_id := old.dossier_id;
```

```ts
/**
 * Envoie une requête de complétion à OpenRouter et renvoie le texte de la réponse, nettoyé.
 * Lève `AiProviderError` en cas d'échec ; ne journalise jamais la requête ni la réponse.
 *
 * @example
 * const text = await completeChat(apiKey, { model: AI_MODEL, messages });
 */
export async function completeChat(
  apiKey: string,
  payload: Record<string, unknown>,
  deps: ProviderDeps = {},
): Promise<string> {
  const resolved: Required<ProviderDeps> = {
    fetchImpl: deps.fetchImpl ?? fetch,
    sleep: deps.sleep ?? defaultSleep,
    now: deps.now ?? Date.now,
  };
  let res: Response;
  try {
    res = await send(resolved, apiKey, JSON.stringify(payload));
  } catch (error) {
    // WHY: on journalise la nature de l'échec, jamais le prompt ni la réponse.
    console.error('[ai] provider error', {
      name: error instanceof Error ? error.name : 'unknown',
    });
    throw new AiProviderError('api');
  }
  if (!res.ok) {
    await res.body?.cancel().catch(() => {});
    console.error('[ai] provider error', { status: res.status });
    throw new AiProviderError('api');
  }

  let body: unknown;
  try {
    body = await res.json();
  } catch (error) {
    console.error('[ai] provider error', {
      read: error instanceof Error ? error.name : 'unknown',
    });
    throw new AiProviderError('api');
  }
  const parsed = ResponseSchema.safeParse(body);
  if (!parsed.success) {
    console.error('[ai] provider error', { shape: 'unexpected' });
    throw new AiProviderError('api');
  }
  const choice = parsed.data.choices[0]!;
  if (choice.error) {
    console.error('[ai] provider error', { choiceError: true });
    throw new AiProviderError('api');
  }
  if (choice.finish_reason === 'error') {
    console.error('[ai] provider error', { finish: 'error' });
    throw new AiProviderError('api');
  }
  if (choice.finish_reason === 'content_filter') throw new AiProviderError('refusal');
  if (choice.finish_reason === 'length') throw new AiProviderError('truncated');
  const text = choice.message?.content?.trim() ?? '';
  if (!text) throw new AiProviderError('empty');
  return text;
}

/**
 * Fournisseur OpenRouter (serveur seulement), modèle Claude Opus 5.5.
 * WHY: `data_collection: 'deny'` écarte les fournisseurs qui entraînent leurs modèles sur les
 * requêtes : les textes des familles ne doivent servir qu'à leur réponse.
 *
 * @example
 * const text = await openRouterProvider(apiKey)(buildImprovePrompt(args));
 */
export function openRouterProvider(apiKey: string, deps: ProviderDeps = {}): ImproveProvider {
  return ({ system, user }) =>
    completeChat(
      apiKey,
      {
        model: AI_MODEL,
        max_tokens: MAX_TOKENS,
        reasoning: { effort: 'low', exclude: true },
        provider: { data_collection: 'deny' },
        messages: [
          { role: 'system', content: system },
          { role: 'user', content: user },
        ],
      },
      deps,
    );
}
```

```ts
import { z } from 'zod';
import { GRID_KEYS } from '@/modules/budget/grid';
import { AMOUNT_MAX } from '@/modules/budget/scenarios';
import { isAiEnabled } from './config';
import { AiProviderError } from './provider';
import { takeAiQuota } from './quota';
import {
  openRouterReceiptProvider,
  type ReceiptImage,
  type ReceiptProvider,
} from './receipt-provider';
import type { AiError } from './types';

/** Ce que l'IA a lu sur un reçu ; chaque champ vaut null quand il est absent ou invalide. */
export interface ReceiptReading {
  amount: number | null;
  date: string | null;
  vendor: string | null;
  gridKey: string | null;
}

export type ReceiptReadResult = { ok: true; data: ReceiptReading } | { ok: false; error: AiError };

const DAY_MS = 24 * 60 * 60 * 1000;

/** Date AAAA-MM-JJ réelle, du 2000-01-01 à demain au plus (mêmes bornes que le registre). */
function isReceiptDate(s: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(s)) return false;
  const date = new Date(`${s}T00:00:00Z`);
  return (
    !Number.isNaN(date.getTime()) &&
    date.toISOString().slice(0, 10) === s &&
    s >= '2000-01-01' &&
    date.getTime() <= Date.now() + DAY_MS
  );
}

/** Fournisseur sans caractère de contrôle, espaces resserrés, 120 caractères au plus. */
function cleanVendor(s: string): string | null {
  const text = [...s]
    .filter((c) => c.charCodeAt(0) >= 32 && c.charCodeAt(0) !== 127)
    .join('')
    .replace(/\s+/g, ' ')
    .trim();
  return text ? [...text].slice(0, 120).join('') : null;
}

// WHY: chaque champ invalide devient null au lieu de rejeter toute la lecture : le résultat
// n'est qu'un préremplissage que le trésorier vérifie.
const ReadingSchema = z.object({
  amount: z.number().int().min(1).max(AMOUNT_MAX).nullable().catch(null),
  date: z.string().refine(isReceiptDate).nullable().catch(null),
  vendor: z.string().transform(cleanVendor).nullable().catch(null),
  gridKey: z
    .string()
    .refine((key) => GRID_KEYS.includes(key))
    .nullable()
    .catch(null),
});

/**
 * Extrait et valide la lecture d'un reçu dans la réponse du modèle ; null si rien n'est lisible.
 *
 * @example
 * parseReceiptReading('{"amount": 45000, "date": null, "vendor": "Mba", "gridKey": "coffin"}');
 */
export function parseReceiptReading(text: string): ReceiptReading | null {
  const start = text.indexOf('{');
  const end = text.lastIndexOf('}');
  if (start < 0 || end <= start) return null;
  let value: unknown;
  try {
    value = JSON.parse(text.slice(start, end + 1));
  } catch {
    return null;
  }
  const parsed = ReadingSchema.safeParse(value);
  if (!parsed.success) return null;
  // WHY: une lecture sans aucun champ ne préremplit rien : on la traite comme un échec.
  return Object.values(parsed.data).every((v) => v === null) ? null : parsed.data;
}

/**
 * Lit la photo d'un reçu pour préremplir une dépense. Consomme le quota d'IA du dossier (même
 * quota que les brouillons), puis envoie seulement l'image. Ne journalise ni la réponse ni le
 * contenu du reçu. L'appelant vérifie le dossier, le rôle et l'image.
 *
 * @example
 * const res = await readReceipt({ dossierId, image: { bytes, mimeType: 'image/jpeg' } });
 */
export async function readReceipt(
  input: { dossierId: string; image: ReceiptImage },
  provider?: ReceiptProvider,
): Promise<ReceiptReadResult> {
  const apiKey = process.env.OPENROUTER_API_KEY;
  // WHY: `apiKey` sert au typage (string) ; `isAiEnabled` reste la source de vérité du drapeau.
  if (!isAiEnabled() || !apiKey) return { ok: false, error: 'unavailable' };
  const quotaError = await takeAiQuota(input.dossierId);
  if (quotaError) return { ok: false, error: quotaError };
  let text: string;
  try {
    text = await (provider ?? openRouterReceiptProvider(apiKey))(input.image);
  } catch (error) {
    const reason = error instanceof AiProviderError ? error.reason : 'unknown';
    console.error('[ai] readReceipt failed', { reason });
    return { ok: false, error: 'failed' };
  }
  const reading = parseReceiptReading(text);
  if (!reading) {
    console.error('[ai] receipt reading rejected', { shape: 'invalid' });
    return { ok: false, error: 'failed' };
  }
  return { ok: true, data: reading };
}
```

```ts
  mimeType: z.enum(RECEIPT_TYPES, { errorMap: () => ({ message: 'receipt type' }) }),
  sizeBytes: z
    .number({ invalid_type_error: 'receipt size', required_error: 'receipt size' })
    .int('receipt size')
    .min(1, 'receipt size')
    .max(RECEIPT_MAX_BYTES, 'receipt size'),
});

/** Désignation d'un reçu d'un dossier (lecture par l'IA). */
export const ReceiptRefSchema = z.object({ dossierId: uuid, receiptId: uuid });

/** Désignation d'un reçu seul (ouverture de la photo). */
export const ReceiptIdSchema = z.object({ receiptId: uuid });

const PNG = [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a];
const ascii = (bytes: Uint8Array, from: number, to: number) =>
  String.fromCharCode(...bytes.subarray(from, to));

/**
 * Type réel d'une image d'après ses premiers octets, ou null.
 * WHY: le type déclaré par le navigateur (et repris par le stockage) ne prouve rien ; seule la
 * signature des octets décide de ce qui part au fournisseur d'IA.
 *
 * @example
 * sniffImageType(bytes); // 'image/jpeg'
 */
export function sniffImageType(bytes: Uint8Array): ReceiptType | null {
  if (bytes.length >= 3 && bytes[0] === 0xff && bytes[1] === 0xd8 && bytes[2] === 0xff) {
    return 'image/jpeg';
  }
  if (bytes.length >= 8 && PNG.every((b, i) => bytes[i] === b)) return 'image/png';
  if (bytes.length >= 12 && ascii(bytes, 0, 4) === 'RIFF' && ascii(bytes, 8, 12) === 'WEBP') {
    return 'image/webp';
  }
  return null;
}
```

```ts
import 'server-only';
import { getSupabaseServer } from '@/lib/supabase/server';
import type { RepoResult } from '@/modules/dossier/repo';
import { RECEIPT_BUCKET, type ReceiptType } from './schema';

/** Durée de vie d'un lien de lecture signé, en secondes (5 minutes). */
export const READ_URL_TTL_SECONDS = 300;

/** Reçu tel que lu en base. */
export interface Receipt {
  id: string;
  dossierId: string;
  entryId: string | null;
  storagePath: string;
  mimeType: ReceiptType;
  sizeBytes: number;
}

const COLUMNS = 'id, dossier_id, entry_id, storage_path, mime_type, size_bytes';

interface ReceiptRow {
  id: string;
  dossier_id: string;
  entry_id: string | null;
  storage_path: string;
  mime_type: ReceiptType;
  size_bytes: number;
}

const toReceipt = (r: ReceiptRow): Receipt => ({
  id: r.id,
  dossierId: r.dossier_id,
  entryId: r.entry_id,
  storagePath: r.storage_path,
  mimeType: r.mime_type,
  sizeBytes: r.size_bytes,
});

function fail(error: { code?: string; message?: string }) {
  return {
    data: null,
    error: { code: error.code || 'unknown', message: error.message || 'receipts error' },
  };
}

// WHY: les erreurs du stockage n'ont pas de code Postgres ; « storage » les distingue.
const storageFail = (error: { message?: string }) => ({
  data: null,
  error: { code: 'storage', message: error.message || 'storage error' },
});

const NO_ROWS = { data: null, error: { code: 'no_rows', message: 'no row matched' } };

/**
 * Prépare un reçu non rattaché (trésorier et plus, vérifié par la base).
 * WHY: chemin, auteur, date et rattachement sont imposés par le trigger ; on n'envoie que le reste.
 */
export async function insertReceipt(
  dossierId: string,
  mimeType: ReceiptType,
  sizeBytes: number,
): Promise<RepoResult<Receipt>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('receipt')
    .insert({ dossier_id: dossierId, mime_type: mimeType, size_bytes: sizeBytes })
    .select(COLUMNS)
    .single<ReceiptRow>();
  if (error) return fail(error);
  return { data: toReceipt(data), error: null };
}

/** Reçu visible de l'utilisateur (RLS), ou null. */
export async function getReceipt(receiptId: string): Promise<RepoResult<Receipt | null>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('receipt')
    .select(COLUMNS)
    .eq('id', receiptId)
    .maybeSingle<ReceiptRow>();
  if (error) {
    console.error('[budget/receipts] getReceipt impossible', { code: error.code });
    return fail(error);
  }
  return { data: data ? toReceipt(data) : null, error: null };
}

/** Rattache un reçu à une dépense (trésorier et plus ; la base vérifie dépense et dossier). */
export async function attachReceipt(
  dossierId: string,
  receiptId: string,
  entryId: string,
): Promise<RepoResult<true>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('receipt')
    .update({ entry_id: entryId })
    .eq('dossier_id', dossierId)
    .eq('id', receiptId)
    .select('id')
    .returns<{ id: string }[]>();
  if (error) return fail(error);
  // WHY: la RLS fait échouer en silence une mise à jour interdite (0 ligne) : on le signale.
  if (!data || data.length === 0) return NO_ROWS;
  return { data: true, error: null };
}

/** Reçus rattachés du dossier visibles de l'utilisateur, par dépense. */
export async function listReceiptsByEntry(
  dossierId: string,
): Promise<RepoResult<Map<string, string>>> {
  const db = await getSupabaseServer();
  const { data, error } = await db
    .from('receipt')
    .select('id, entry_id')
    .eq('dossier_id', dossierId)
    .not('entry_id', 'is', null)
    .returns<{ id: string; entry_id: string }[]>();
  if (error) {
    console.error('[budget/receipts] listReceiptsByEntry impossible', { code: error.code });
    return fail(error);
  }
  return { data: new Map((data ?? []).map((r) => [r.entry_id, r.id])), error: null };
}

/**
 * Lien d'envoi signé pour le chemin d'un reçu préparé (policy d'insertion du bucket).
 * WHY: Supabase fixe sa durée (2 heures) ; il ne sert qu'une fois, le bucket refusant tout
 * remplacement.
 */
export async function createUploadUrl(
  path: string,
): Promise<RepoResult<{ path: string; token: string }>> {
  const db = await getSupabaseServer();
  const { data, error } = await db.storage.from(RECEIPT_BUCKET).createSignedUploadUrl(path);
  if (error) return storageFail(error);
  return { data: { path: data.path, token: data.token }, error: null };
}

/** Octets de la photo d'un reçu visible de l'utilisateur. */
export async function downloadReceipt(path: string): Promise<RepoResult<Uint8Array>> {
  const db = await getSupabaseServer();
  const { data, error } = await db.storage.from(RECEIPT_BUCKET).download(path);
  if (error) return storageFail(error);
  return { data: new Uint8Array(await data.arrayBuffer()), error: null };
}
```

```ts
import 'server-only';
import { isAiEnabled } from '@/modules/ai/config';
import { readReceipt } from '@/modules/ai/receipt';
import type { ReceiptProvider } from '@/modules/ai/receipt-provider';
import { getMyRole } from '@/modules/dossier/repo';
import { hasRole } from '@/modules/dossier/roles';
import { budgetGate } from '../gate';
import { listLines } from '../lines/repo';
import * as repo from './repo';
import {
  PrepareReceiptSchema,
  RECEIPT_MAX_BYTES,
  ReceiptIdSchema,
  ReceiptRefSchema,
  sniffImageType,
  type ReceiptPrefill,
} from './schema';

export type ReceiptsError =
  | 'validation'
  | 'forbidden'
  | 'not_found'
  | 'unauthenticated'
  | 'receipt_type'
  | 'receipt_size'
  | 'too_many_receipts'
  | 'unknown';

/** Erreurs de la lecture : celles des reçus, plus celles de l'IA (saisie manuelle possible). */
export type ReadError = ReceiptsError | 'unavailable' | 'quota' | 'failed';

export type ReceiptsResult<T> = { ok: true; data: T } | { ok: false; error: ReceiptsError };
export type ReadResult = { ok: true; data: ReceiptPrefill } | { ok: false; error: ReadError };

/** Envoi préparé : le navigateur envoie la photo au stockage avec ce chemin et ce jeton. */
export interface PreparedUpload {
  receiptId: string;
  path: string;
  token: string;
}

const CODES: Record<string, ReceiptsError> = {
  '42501': 'forbidden',
  '28000': 'unauthenticated',
  // WHY: JWT expiré signalé par PostgREST.
  PGRST301: 'unauthenticated',
  '23514': 'validation',
  '22P02': 'validation',
  // WHY: limite de 200 reçus par dossier (trigger de receipt).
  TL007: 'too_many_receipts',
  no_rows: 'not_found',
};

function fromRepo(error: { code: string }, scope: string): { ok: false; error: ReceiptsError } {
  const mapped = CODES[error.code];
  if (!mapped) console.error(`[budget/receipts] ${scope} failed`, { code: error.code });
  return { ok: false, error: mapped ?? 'unknown' };
}

/**
 * Porte des reçus : dossier ouvert au budget, puis rôle trésorier ou plus.
 * WHY: la lecture consomme le quota d'IA (ouvert dès le contributeur) ; on la réserve à qui
 * saisit les dépenses. La RLS reste le garde-fou de la base.
 */
async function managerGate(dossierId: string): Promise<ReceiptsError | null> {
  const blocked = await budgetGate(dossierId);
  if (blocked) return blocked;
  return hasRole(await getMyRole(dossierId), 'treasurer') ? null : 'forbidden';
}

/**
 * Prépare l'envoi d'une photo de reçu : ligne `receipt` non rattachée et lien d'envoi signé.
 *
 * @example
 * await prepareReceiptUpload({ dossierId, mimeType: 'image/jpeg', sizeBytes: 812_000 });
 */
export async function prepareReceiptUpload(raw: unknown): Promise<ReceiptsResult<PreparedUpload>> {
  const input = PrepareReceiptSchema.safeParse(raw);
  if (!input.success) {
    const field = input.error.issues[0]?.path[0];
    const error =
      field === 'mimeType' ? 'receipt_type' : field === 'sizeBytes' ? 'receipt_size' : 'validation';
    return { ok: false, error };
  }
  const { dossierId, mimeType, sizeBytes } = input.data;
  const blocked = await managerGate(dossierId);
  if (blocked) return { ok: false, error: blocked };
  const receipt = await repo.insertReceipt(dossierId, mimeType, sizeBytes);
  if (receipt.error) return fromRepo(receipt.error, 'prepare');
  const upload = await repo.createUploadUrl(receipt.data.storagePath);
  if (upload.error) return fromRepo(upload.error, 'createUploadUrl');
  return {
    ok: true,
    data: { receiptId: receipt.data.id, path: upload.data.path, token: upload.data.token },
  };
}

/**
 * Lit un reçu envoyé et non rattaché pour préremplir la dépense (trésorier et plus).
 * Un échec de l'IA (`unavailable`, `quota`, `failed`) laisse la saisie manuelle possible.
 *
 * @example
 * const res = await readReceiptPrefill({ dossierId, receiptId });
 */
export async function readReceiptPrefill(
  raw: unknown,
  provider?: ReceiptProvider,
): Promise<ReadResult> {
  const input = ReceiptRefSchema.safeParse(raw);
  if (!input.success) return { ok: false, error: 'validation' };
  const { dossierId, receiptId } = input.data;
  const blocked = await managerGate(dossierId);
  if (blocked) return { ok: false, error: blocked };
  // WHY: sans clé, inutile de télécharger la photo : la saisie reste manuelle.
  if (!isAiEnabled()) return { ok: false, error: 'unavailable' };
  const receipt = await repo.getReceipt(receiptId);
  if (receipt.error) return fromRepo(receipt.error, 'getReceipt');
  if (!receipt.data || receipt.data.dossierId !== dossierId) {
    return { ok: false, error: 'not_found' };
  }
  // WHY: un reçu déjà joint a déjà servi ; le relire consommerait le quota pour rien.
  if (receipt.data.entryId) return { ok: false, error: 'validation' };

  // WHY: télécharger et lire les postes avant de consommer le quota : une lecture en échec ne
  // coûte pas d'appel.
  const [file, lines] = await Promise.all([
    repo.downloadReceipt(receipt.data.storagePath),
    listLines(dossierId),
  ]);
  if (file.error || lines.error) {
    console.error('[budget/receipts] read inputs unavailable', {
      file: file.error?.code ?? null,
      lines: lines.error?.code ?? null,
    });
    return { ok: false, error: 'failed' };
  }
  if (file.data.length > RECEIPT_MAX_BYTES) return { ok: false, error: 'receipt_size' };
  const mimeType = sniffImageType(file.data);
  if (!mimeType) return { ok: false, error: 'receipt_type' };

  const reading = await readReceipt({ dossierId, image: { bytes: file.data, mimeType } }, provider);
  if (!reading.ok) return { ok: false, error: reading.error };
  const { amount, date, vendor, gridKey } = reading.data;
  const line = gridKey ? lines.data.find((l) => l.gridKey === gridKey) : undefined;
  return {
    ok: true,
    data: { amount, occurredOn: date, partyName: vendor, budgetLineId: line?.id ?? null },
  };
}

/**
 * Lien de lecture signé (5 minutes) de la photo d'un reçu visible de l'utilisateur.
 * WHY: un identifiant invalide et un reçu invisible donnent tous deux `not_found`.
 */
export async function openReceipt(raw: unknown): Promise<ReceiptsResult<string>> {
  const input = ReceiptIdSchema.safeParse(raw);
  if (!input.success) return { ok: false, error: 'not_found' };
  const receipt = await repo.getReceipt(input.data.receiptId);
  if (receipt.error) return fromRepo(receipt.error, 'openReceipt');
  if (!receipt.data) return { ok: false, error: 'not_found' };
  const url = await repo.signedReadUrl(receipt.data.storagePath);
  if (url.error) return fromRepo(url.error, 'signedReadUrl');
  return { ok: true, data: url.data };
}
```

```ts
import 'server-only';
import { getCurrentUser } from '@/lib/supabase/server';
import { openReceipt } from './service';

const NO_STORE = { 'Cache-Control': 'no-store' };

/**
 * Réponse de « Voir le reçu » : redirection vers un lien signé de 5 minutes créé à la demande.
 * WHY: un lien signé posé dans la page expirerait avant d'être ouvert ; la route en crée un neuf
 * à chaque clic. Absent ou interdit donnent 404, pour ne pas révéler l'existence d'un reçu.
 *
 * @example
 * export async function GET(_req, { params }) { return receiptRedirect((await params).receiptId); }
 */
export async function receiptRedirect(receiptId: string): Promise<Response> {
  if (!(await getCurrentUser())) return new Response(null, { status: 401, headers: NO_STORE });
  const res = await openReceipt({ receiptId });
  if (!res.ok) {
    const status = res.error === 'not_found' || res.error === 'forbidden' ? 404 : 502;
    return new Response(null, { status, headers: NO_STORE });
  }
  return new Response(null, {
    status: 303,
    headers: { Location: res.data, 'Referrer-Policy': 'no-referrer', ...NO_STORE },
  });
}
```

```tsx
  'border-border bg-background text-foreground w-full rounded-xl border px-3 py-2 disabled:opacity-60';
const LABEL = 'text-foreground text-sm';

/**
 * Champs accessibles d'un formulaire du registre : identifiants, libellés, erreur sous chaque
 * champ et erreur générale.
 * WHY: sorti d'EntryForm (limite de 300 lignes) ; le comportement est inchangé.

 * const { uid, a11y, wrap, input, generalError } = useEntryFields(state, ['amount', 'note']);

export function useEntryFields(state: LedgerFormState | null, shown: readonly string[]) {
  const t = useTranslations('ledger');
  const tErrors = useTranslations('dossier.errors');
  const uid = useId();

  const fieldError = (name: string): string | null => {
    const message = state?.fieldErrors?.[name];
    if (!message) return null;
    const textKey = FIELD_MESSAGES[message];
    return textKey ? t(textKey) : tErrors('validation');
  };
  const idOf = (name: string) => `${uid}-${name}`;
  const errorIdOf = (name: string) => `${uid}-${name}-error`;
  const a11y = (name: string, hintId?: string) => {
    const error = fieldError(name);
    const describedBy = [hintId, error ? errorIdOf(name) : undefined].filter(Boolean).join(' ');
    return {
      id: idOf(name),
      name,
      'aria-invalid': error ? true : undefined,
      'aria-describedby': describedBy || undefined,
    } as const;
  };
  const wrap = (name: string, label: string, control: ReactNode, hint?: ReactNode) => {
    const error = fieldError(name);
    return (
      <div className="space-y-1">
        <label htmlFor={idOf(name)} className={`block ${LABEL}`}>
          {label}
        </label>
        {control}
        {hint}
        {error && (
          <p id={errorIdOf(name)} role="alert" className="text-destructive text-sm">
            {error}
          </p>
        )}
      </div>
    );
  };
  const input = (name: string, label: string, props: InputHTMLAttributes<HTMLInputElement>) =>
    wrap(name, label, <input className={FIELD} {...a11y(name)} {...props} />);
```

```ts
const get = (messages: unknown, path: string): unknown =>
  path
    .split('.')
    .reduce<unknown>(
      (node, part) =>
        node && typeof node === 'object' ? (node as Record<string, unknown>)[part] : undefined,
      messages,
    );
const isFilled = (value: unknown) => typeof value === 'string' && value.trim() !== '';

function leafPaths(node: unknown, prefix = ''): string[] {
  if (node && typeof node === 'object') {
    return Object.entries(node).flatMap(([k, v]) => leafPaths(v, prefix ? `${prefix}.${k}` : k));
  }
  return [prefix];
}

const placeholders = (value: unknown): string[] =>
  typeof value === 'string'
    ? [...value.matchAll(/\{(\w+)/g)].map((m) => m[1] as string).sort()
    : [];

const PATHS = [
  ...['label', 'hint', 'uploading', 'reading', 'read'].map((k) => `receipts.capture.${k}`),
  ...['unavailable', 'quota', 'failed'].map((k) => `receipts.manual.${k}`),
  ...['receipt_type', 'receipt_size', 'too_many_receipts', 'upload_failed'].map(
    (k) => `receipts.errors.${k}`,
  ),
];

describe.each([
  ['fr', fr],
  ['en', en],
])('textes des reçus (%s)', (_locale, messages) => {
  it('couvrent chaque état et chaque erreur', () => {
    expect(PATHS.filter((path) => !isFilled(get(messages, path)))).toEqual([]);
  });
```

```ts
import type { ReadError } from '../service';

/** Erreur affichable du reçu : celles du service, plus l'envoi au stockage en échec. */
export type CaptureError = ReadError | 'upload_failed';

const SPECIFIC: ReadonlySet<CaptureError> = new Set([
  'receipt_type',
  'receipt_size',
  'too_many_receipts',
  'upload_failed',
]);
const MANUAL: ReadonlySet<CaptureError> = new Set(['unavailable', 'quota', 'failed']);

/** Vrai quand l'IA n'a pas lu le reçu mais que la photo reste jointe (saisie manuelle). */
export const isManualFallback = (error: CaptureError) => MANUAL.has(error);

/**
 * Texte d'une erreur du reçu, à partir d'un traducteur sans espace de noms.
 *
 * @example
 * const t = useTranslations();
 * receiptErrorText('quota', t); // « Photo jointe. La limite de lectures… »
 */
export function receiptErrorText(error: CaptureError, t: (key: string) => string): string {
  if (MANUAL.has(error)) return t(`receipts.manual.${error}`);
  return t(SPECIFIC.has(error) ? `receipts.errors.${error}` : `dossier.errors.${error}`);
}
```

```ts
import type { ReceiptPrefill } from '../schema';

/**
 * Propose dans le formulaire de dépense ce que l'IA a lu sur le reçu.
 * WHY: un champ déjà saisi n'est jamais remplacé ; le trésorier reste maître de la saisie et
 * valide toujours. Un poste absent de la liste n'est pas choisi.
 *
 * @example
 * prefillExpense(formRef.current, { amount: 45_000, occurredOn: null, partyName: 'Mba', budgetLineId: null });
 */
export function prefillExpense(form: HTMLFormElement | null, prefill: ReceiptPrefill): void {
  if (!form) return;
  const set = (name: string, value: string | null) => {
    if (value === null) return;
    const el = form.elements.namedItem(name);
    if (!(el instanceof HTMLInputElement || el instanceof HTMLSelectElement)) return;
    if (el.value.trim() !== '') return;
    if (el instanceof HTMLSelectElement && ![...el.options].some((o) => o.value === value)) return;
    el.value = value;
  };
  set('amount', prefill.amount === null ? null : String(prefill.amount));
  set('occurredOn', prefill.occurredOn);
  set('partyName', prefill.partyName);
  set('budgetLineId', prefill.budgetLineId);
}
```

```tsx
'use client';

import { useId, useState } from 'react';
import type { ChangeEvent } from 'react';
import { useTranslations } from 'next-intl';
import { getSupabaseBrowser } from '@/lib/supabase/client';
import { prepareReceiptUploadAction, readReceiptAction } from '../actions';
import {
  isReceiptType,
  RECEIPT_BUCKET,
  RECEIPT_MAX_BYTES,
  RECEIPT_TYPES,
  type ReceiptPrefill,
} from '../schema';
import { isManualFallback, receiptErrorText, type CaptureError } from './receiptError';

interface Props {
  dossierId: string;
  /** Reçu joint à la dépense (son identifiant), ou null quand aucun reçu n'est joint. */
  onAttach: (receiptId: string | null) => void;
  /** Ce que l'IA a lu, à proposer dans le formulaire. */
  onRead: (prefill: ReceiptPrefill) => void;
}

type Status =
  | { kind: 'idle' }
  | { kind: 'busy'; text: string }
  | { kind: 'info'; text: string }
  | { kind: 'error'; text: string };

/**
 * Photo d'un reçu : contrôle du type et de la taille, envoi direct au stockage par un lien signé
 * préparé par le serveur, puis lecture par l'IA pour préremplir la dépense.
 * WHY: le champ de fichier n'a pas de `name` : la photo ne part jamais avec le formulaire de
 * dépense (seul l'identifiant du reçu y figure). Sans `capture`, le téléphone propose l'appareil
 * photo ou la galerie.
 *
 * @example
 * <ReceiptCapture dossierId={id} onAttach={setReceiptId} onRead={(p) => prefillExpense(form, p)} />
 */
export function ReceiptCapture({ dossierId, onAttach, onRead }: Props) {
  const t = useTranslations('receipts.capture');
  const tRoot = useTranslations();
  const [status, setStatus] = useState<Status>({ kind: 'idle' });
  const id = useId();
  const hintId = `${id}-hint`;
  const fail = (error: CaptureError) =>
    setStatus({ kind: 'error', text: receiptErrorText(error, tRoot) });

  const handleFile = async (file: File) => {
    if (!isReceiptType(file.type)) return fail('receipt_type');
    if (file.size < 1 || file.size > RECEIPT_MAX_BYTES) return fail('receipt_size');
    setStatus({ kind: 'busy', text: t('uploading') });
    const prepared = await prepareReceiptUploadAction({
      dossierId,
      mimeType: file.type,
      sizeBytes: file.size,
    });
    if (!prepared.ok) return fail(prepared.error);
    const { error } = await getSupabaseBrowser()
      .storage.from(RECEIPT_BUCKET)
      .uploadToSignedUrl(prepared.data.path, prepared.data.token, file, {
        contentType: file.type,
      });
    if (error) return fail('upload_failed');
    onAttach(prepared.data.receiptId);
    setStatus({ kind: 'busy', text: t('reading') });
    const read = await readReceiptAction({ dossierId, receiptId: prepared.data.receiptId });
    if (read.ok) {
      onRead(read.data);
      return setStatus({ kind: 'info', text: t('read') });
    }
    // WHY: l'IA n'a pas lu le reçu, mais la photo est bonne : elle reste jointe.
    if (isManualFallback(read.error)) {
      return setStatus({ kind: 'info', text: receiptErrorText(read.error, tRoot) });
    }
    // WHY: une photo refusée à la lecture (pas une image, trop lourde, droits) n'est pas jointe.
    onAttach(null);
    fail(read.error);
  };

  const onChange = (e: ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    onAttach(null);
    if (!file) return setStatus({ kind: 'idle' });
    // WHY: une action serveur ou le réseau peuvent lever ; la saisie manuelle reste possible.
    handleFile(file).catch(() => fail('upload_failed'));
  };

  return (
    <div className="space-y-1">
      <label htmlFor={id} className="text-foreground block text-sm">
        {t('label')}
      </label>
      <input
        id={id}
        type="file"
        accept={RECEIPT_TYPES.join(',')}
        disabled={status.kind === 'busy'}
        aria-describedby={hintId}
        onChange={onChange}
        className="text-foreground block w-full text-sm"
      />
      <p id={hintId} className="text-foreground text-sm">
        {t('hint')}
      </p>
      <p role="status" className="text-foreground text-sm">
        {status.kind === 'busy' || status.kind === 'info' ? status.text : ''}
      </p>
      {status.kind === 'error' && (
        <p role="alert" className="text-destructive text-sm">
          {status.text}
        </p>
      )}
    </div>
  );
}
```
